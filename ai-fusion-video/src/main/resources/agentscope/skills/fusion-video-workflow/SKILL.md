# 融光视频工作流

处理跨阶段视频任务时，先识别当前项目、剧本、集、场景和分镜标识，再选择最小范围的读取工具确认现状。

执行任务时遵循这些原则：

1. 将目标拆成“内容准备 → 视觉规划 → 素材生成 → 视频生成/合成 → 结果核验”几个可独立验证的阶段。
2. 优先复用已经存在的剧本、角色、场景、分镜和素材；除非用户明确要求，不重复创建同一对象。
3. 调用写入或生成类工具前，确认其必需标识和输入来源；调用后记录返回的对象标识、状态和失败原因。
4. 批量任务先用一个代表性对象验证参数，再扩展到其余对象；对失败项单独重试，不覆盖成功结果。
5. 回复用户时说明已完成的阶段、生成结果的位置，以及仍需用户决定或补充的内容。

如果可用工具不足以完成某一阶段，明确指出缺少的能力，不虚构执行结果。
