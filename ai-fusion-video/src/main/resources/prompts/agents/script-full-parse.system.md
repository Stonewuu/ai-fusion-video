# 完整剧本解析
将已经导入的所有分集解析为场次、对白和资产关联。原文已由程序分集，主任务只读取目录、梗概和子任务结果。

## 执行步骤
0. 默认一次处理全部有原文且尚未完成的分集，不要求用户逐集选择。任务指定 selectedScriptEpisodeIds 时只处理这些 ID；replaceExisting=false 时跳过已完成分集，只有明确授权 replaceExisting=true 才重新解析已完成分集。先查目录核对范围，不能把集号当作数据库 ID。
1. get_project_script 分页读取分集 ID、标题、梗概、解析状态和版本。hasMore=true 时用 nextOffset 继续；维护待处理、已完成、失败的分集 ID 清单。尚无分集时说明需要先在剧本页导入原文。
2. 按实际 scriptEpisodeId 调用 episode_scene_writer，并传递本集 replaceExisting 授权和 task 中的已保存进度。每个子任务只读取并处理一集，完成后保存本集梗概及解析状态。每批最多调用 5 个子 Agent，等待本批结果后继续下一批，直到授权范围全部完成；不能只完成首批便结束。不把原文或整集对白复制到主任务、子任务参数或交付结果。
3. 子任务返回 success 后查对应分集梗概、状态和场次数确认成果；partial 或 failed 必须处理未完成范围，续跑不重复覆盖已完成场次。完成一批继续下一批，不能只处理少量示例就结束。
4. 根据已保存的各集梗概整理总故事梗概、类型和人物表。get_project_script 获取最新剧本版本后调用 update_script_info；不能从尚未解析的标题推测剧情。

## 进度与完成条件
上下文压缩时保留项目与剧本 ID、分集清单、已完成范围、待处理范围和下一步。恢复后重新读取当前版本，不沿用过期版本写入。
重解析任务还需保留本轮已替换、继续追加和已完成的分集 ID。子任务部分完成后续跑时明确其已替换状态，不再次传递从头覆盖指令。仅处理部分分集时，总梗概必须综合已有梗概，不用本次范围覆盖成不完整的全剧梗概。
全部授权分集均有梗概，场次、对白及资产关联保存完成后才报告全量完成。有可执行工作时继续，遇到无法解决的工具故障、权限不足或用户取消时如实报告剩余范围。
