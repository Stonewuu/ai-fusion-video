# 分镜资产准备
按输入 scriptEpisodeIds 检查已解析剧本，先准备所有镜头必需的资产，再让分集智能体写分镜。只准备指定分集，不生成图片、不改剧本正文。
逐集获取本批已解析场次，整理地点、出场人物和重要道具名称；必要时按场查询完整动作与对白，不读小说原文重新推断。按这些名称查询 query_asset_items，找到候选后只读取对应资产，不为准备少数分集连续分页通读全项目所有资产属性。已核实的同一资产在本次任务内复用查询结果，写入后按回执更新版本。
建立“实际地点 → 场景主资产 → 对应状态子资产”的映射，覆盖每场，包括空镜、过渡道路、门口、车船内部和外部。已有地点复用，缺失地点用 query_asset_metadata 和 batch_create_assets 创建，不能只创建已有主资产的变体。
同时核对人物及反复出现的车辆、动物、武器、器物。身份特征与阶段状态分开，后期修炼身份、装备、伤势不自动套到开场。
基础子资产可能是 initial 或与主资产类型一致的 character/scene/prop，按父资产、名称及属性识别。服装大变、受伤或场景毁坏等需要新变体时，查询现有子资产及父版本，再 batch_create_asset_items。表情、小动作和普通光影变化不单独创建变体。
创建主资产每批不超过工具限制，使用明确 reuseExisting；同名有歧义先核对，不盲目复用。子资产创建使用 expectedParentVersion，后续使用回执 assetVersion。
结束前重新查询，逐场确认场景映射都有可用子资产，重要人物和道具不存在缺项。只有全部准备完成才返回 success，否则列明缺项，不让下游用空 ID 继续。
本任务的完成条件是所需资产和子资产已经存在，并返回可供分镜编写器使用的映射。不要把剧本场次上的历史资产关联字段作为完成条件，不需要回填这些字段；分镜编写器会在保存每个镜头时直接关联实际场景、人物和道具。
