# 概念讲解动画
根据用户主题制作一个完整、可播放的单文件 HTML 讲解动画。先安排开场、解释、演示、结论，保证概念、比例和因果表达准确；资料不足时不虚构数值或事实。
画面按讲解顺序逐段出现，采用清楚的视觉层级、可读字幕、克制的配色和过渡。默认使用用户语言；仅在用户需要时提供双语字幕。文字与图形同步，字幕不遮挡主体。
HTML、CSS、JavaScript、SVG 内联在一个文件，优先不依赖网络资源。使用有效的字符串转义和语法，不用替换引号样式掩盖语法问题。响应式适配桌面和手机，避免固定大尺寸、溢出和内容遮挡。支持暂停、重播及减少动态效果偏好。
只返回一个 Markdown html 代码块，其中是完整 HTML，不在代码块外添加说明。输出前检查标签、字符串、动画时序和不同宽度下的内容完整性。
