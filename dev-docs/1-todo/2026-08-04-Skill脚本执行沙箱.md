# Skill 脚本执行沙箱技术债务

- 状态：待实现
- 记录日期：2026-07-29
- 关联功能：用户 Skill ZIP/目录导入第一期
- 官方格式参考：https://agentskills.io/specification

## 第一阶段已完成的边界

第一阶段支持把完整 Skill 目录导入用户工作区，包括 `SKILL.md`、`references/`、
`assets/`、`scripts/` 和其他资源文件。文本文件按 UTF-8 保存，二进制文件按 Base64
保存。AgentScope 可以通过用户隔离的工作区 Skill 仓库延迟读取文本说明和引用资源。

`scripts/` 当前只保存、不执行。导入包中的 `allowed-tools` 也只作为原始 frontmatter
保留，不会转换为平台工具授权。

## 为什么不能直接开启 Shell

当前 Harness 明确调用了 `disableShellTool()`，导入来源又可能包含任意代码。直接为
Skill 开启本机 Shell 会让代码继承后端进程的文件、网络、环境变量和服务账号权限，
可能造成数据泄露、横向访问、资源耗尽或宿主机破坏。因此脚本执行必须作为独立安全
能力设计，不能作为导入功能的附带开关。

## 后续实现范围

### 1. 隔离执行环境

- 每次脚本调用使用一次性容器或等价的强隔离沙箱。
- Skill 目录只读挂载，输出写入独立临时目录。
- 默认禁网；如需联网，必须通过显式域名白名单和代理审计。
- 不注入后端环境变量、云凭据、数据库凭据或用户令牌。
- 禁止访问 Docker Socket、宿主机路径和其他用户工作区。

### 2. 资源限制

- 限制 CPU、内存、进程数、磁盘空间、输出字节数和执行时间。
- 超时、用户取消和 Agent Run 终止时必须同步停止沙箱。
- 限制可执行解释器和版本，首批建议仅开放固定版本的 Python 与 Node.js。
- 禁止运行时全局安装依赖；依赖必须来自预构建镜像或受控的项目级缓存。

### 3. 权限模型

- `allowed-tools` 只能作为请求权限的声明，不能作为自动批准依据。
- 平台维护实际能力白名单，按 Skill、用户、Agent 和环境取交集。
- 网络、文件写入、外部工具调用等高风险能力应要求单独授权。
- 同名 Skill 覆盖后必须重新评估权限，旧版本授权不能静默继承到新代码。

### 4. 审计与供应链

- 记录 Skill 名称、内容哈希、脚本路径、解释器、参数、发起用户、Agent Run、耗时和结果。
- 保存导入时的每个文件 SHA-256，并在执行前复核，避免导入后内容被替换。
- 增加恶意代码与敏感信息扫描接口，扫描失败默认禁止执行。
- 对覆盖导入保留版本或可恢复快照，支持追踪是哪一版脚本产生了结果。

### 5. AgentScope 集成点

- `AgentScopeHarnessFactory`：继续保持 Shell 默认关闭，只为受控脚本工具注册平台适配器。
- `AgentUserSkillService`：提供按用户和 Skill 名称读取只读文件快照及内容哈希的能力。
- `AgentSkillImportService`：把脚本存在性、文件哈希和兼容性要求纳入导入报告。
- Agent Run 生命周期：把沙箱句柄纳入中断、超时、租约回收和资源关闭流程。

## 建议 API 形态

平台工具应使用结构化参数，而不是开放任意 Shell，例如：

```json
{
  "skill": "pdf-processing",
  "script": "scripts/extract.py",
  "args": ["/inputs/document.pdf"],
  "timeoutSeconds": 30
}
```

服务端必须重新验证 Skill 所有权、脚本相对路径、文件哈希、解释器和权限，不接受
命令字符串、管道、重定向、环境变量表达式或工作目录逃逸。

## 验收标准

- 恶意路径、符号链接、命令拼接和解释器逃逸无法访问 Skill 目录外的内容。
- 两个用户执行同名 Skill 时文件、进程、输出和缓存完全隔离。
- 禁网模式下无法通过 DNS、HTTP、原始 Socket 或代理环境变量出网。
- CPU、内存、磁盘和超时限制均有自动化测试，并能可靠清理残留进程。
- 覆盖 Skill 后旧哈希脚本不能继续执行。
- `allowed-tools` 不会绕过平台白名单或用户确认。
- 审计记录能够从 Agent Run 追溯到具体 Skill 版本和脚本哈希。

## 推荐实施顺序

1. 只读脚本快照、内容哈希和审计数据模型。
2. 单机一次性沙箱原型，默认禁网、无凭据、固定解释器。
3. Agent Run 中断与资源回收集成。
4. 权限申请、用户确认和管理员策略。
5. 多实例调度、镜像治理、扫描与生产压测。
