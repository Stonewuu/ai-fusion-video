# v1.4.0 更新日志

- **长篇剧本导入。** 支持上传最高 100 MiB 的 TXT 或 Markdown 文件，也可以直接粘贴原文。导入时按章节标题识别分集，预览中可以搜索分集、检查重名、改名、拆分、合并、删除或撤销删除。确认后可追加到现有剧本，也可替换原分集。
- **按集解析与分镜关联。** 可以一次解析所有待处理分集，也可以指定范围。默认保留已有场次并补齐内容，重新解析前会提示确认。剧本和分镜可分别清空，替换剧本后可以把已有分镜重新关联到新分集并保留镜头。
- **长目录和资产编辑。** 剧本目录、分镜表格和卡片按需加载，长项目滚动时只渲染附近的行。窄屏上可从资产目录打开详情、编辑主资产或子资产，返回目录时保留搜索条件和滚动位置。
- **融光助手。** 修复推理、回复、工具参数或结果过长导致会话历史保存失败的问题。升级后，后台可从保留的运行记录补回未保存的消息。剧本解析、分镜和生成任务共用每个父任务的 5 个并行子任务名额，其余子任务排队执行。
- **APIXO 模型接入。** 可在 AI 模型设置中配置 APIXO，选择对话、图片和视频模型。生图支持文本生成和参考图编辑，生视频可按模型使用首尾帧、参考图或参考视频。
- **ComfyUI 媒体输入。** 工作流可以把媒体输入设为可选。试运行支持上传图片、音频和视频，校验时会指出仍连接到必填输入的位置。

从 v1.3.1 升级时，后端会在启动时自动扩展 MySQL 中保存会话消息和运行事件的字段。
