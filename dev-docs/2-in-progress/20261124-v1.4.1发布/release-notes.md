# v1.4.1 更新日志

- **画布快捷生成。** 选中图片、视频或文本生成节点后，可直接在节点下方编辑描述、选择模型、调整参数并生成。连线中的文字和参考素材自动显示，生成结果可在节点上查看，图片支持候选切换和放大，视频支持就地播放。
- **文本 AI 写作。** 文本节点可创建相连的生成文本节点，生成结果支持一键写回原文，并可撤销。正文编辑和生成表单支持快捷键保存或生成。
- **画布编辑体验。** 统一节点与工具栏样式，节点配置改为就近打开的悬浮面板，侧边抽屉展开时不再挤压画布。参考素材可直接断开连线，也可从输入端口拖向空白处添加前置节点。
- **模型选择。** 画布模型列表展示厂商图标和模型编码，选项较多时可搜索筛选。
- **分镜合成。** 修复视频音轨长于画面时，下一镜头延迟开始的问题。合成按画面时长裁剪长音轨、补齐短音轨，并保留音轨延后开始的时间关系。

已有成片不会自动替换；受长音轨停顿影响的视频在升级后重新合成即可。
