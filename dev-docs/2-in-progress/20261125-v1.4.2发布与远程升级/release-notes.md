# v1.4.2 更新日志

## 智能助手与 Pipeline

- 优化对话保存方式，流式片段放入 Redis，完整回复和工具记录保存到数据库，减少运行中的数据库写入。
- 关闭页面后重新打开，可以恢复历史消息、尚未完成的回复和子任务状态，并继续查看实时输出。
- 任务结束后保留 24 小时流式缓存。缓存过期后仍可查看完整历史，并在原会话继续对话或继续执行 Pipeline。
- 修复多子任务历史中的重复卡片、内部输入混入用户消息，以及取消后子任务状态显示不准确的问题。
- 取消时保留已输出内容；父任务取消不会把已经完成的子任务改成取消。

## 模型配置

- 调整服务和模型的列表、卡片及编辑界面，支持按类型和启停状态筛选。
- 管理页可以查看已停用模型，调整默认模型、启停状态和测试连接更方便。
- 改进远程模型选择、配置导入导出和参数校验。

## 图片预览

- 为画布、资产和生成结果中的图片预览补充主题背景，改善透明图片的显示效果。
- 修复 Docker 部署中密码找回验证码日志未输出的问题。

## 升级说明

升级时保持数据库、Redis、媒体与 Agent 工作目录的数据卷。应用启动会执行 `V1.1.4.2.0` 数据库迁移，已有会话仍可读取；用户刷新网页后使用新版本。
