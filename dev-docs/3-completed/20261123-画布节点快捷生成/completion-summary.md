# 画布节点快捷生成交付

选中生图或生视频节点后，直接在节点下方编辑本次描述、选择模型、调整输出参数并生成。连线提供的文字和参考素材会自动显示；生成结果保留在节点上，图片支持候选切换和放大，视频支持就地播放。

## 页面与交互

- 参考 LibTV 编辑器，将生成节点改为画面主体、外置名称与轻量状态，移除彩色标题栏、整条运行状态和多余结果分区。
- 快捷生成区使用素材行、连线提示词、本次描述和底部操作栏。比例、分辨率、数量与视频时长集中到输出参数弹层，其余参数按需打开。
- 工具栏与收起的侧边栏改为图标入口；窄屏模型选择独占一行，保持生成按钮可见。
- 草稿按节点保存。上游更新会刷新输入预览，补充描述保持独立；有配置冲突时先确认修改内容。
- 输入缺失、来源失效和生成错误给出具体对象及处理入口，清理无助于当前操作的解释和防御性文案。

## 生成与输入处理

- 新增节点输入预览接口，复用文本组合、静态素材、项目资源与固定结果的解析和权限校验，并检查画布版本。
- 图片与视频配置增加补充描述，提交时与连线文字合并；生成前保存当前节点草稿，复用当前可用的上游结果。
- 上游生成结果未完成或已过期时，提示处理对应节点；一次快捷生成不会隐式提交额外的上游生成任务。
- 保留原有运行、协作、撤销、结果历史与资源鉴权入口。

## 验证

- 前端 TypeScript、修改范围 ESLint、94 项画布回归测试与生产构建通过。
- 后端输入组合、模型约束、预览权限、画布版本冲突、过期产物与生成 HTTP 集成测试通过。
- Chrome 验证了图片与视频的自动输入、草稿切换、上游文字同步、参数修改、生成提交、候选切换、放大预览和视频播放。
- 桌面、1366×768 和 390×844 窗口验证明暗主题、表单首尾与中间字段、滚动、焦点、安全边距、校验和禁用状态。
- 浏览器生成测试使用本地模拟接口，核对收到的合并提示词、参考图、1536×864 图片尺寸和 4 秒视频时长；未调用付费模型供应商。
