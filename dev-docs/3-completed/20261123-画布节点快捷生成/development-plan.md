# 画布节点快捷生成

生图与生视频节点选中后，在节点下方展开统一的生成区，展示连线带入的文字和参考素材，直接编辑参数、生成和查看节点结果。

1. 复用后端输入解析规则，提供选中节点的上游输入预览；补充要求独立保存。
2. 参考 LibTV 编辑器，将画面作为节点主体，名称与状态置于画面上方；在节点下方展开紧凑的快捷生成区。
3. 提交前保存当前草稿、检查上游结果，复用已有结果生成当前节点。
4. 验证文字与素材绑定、草稿切换、生成结果、权限及明暗主题和窄屏表单。

文案只表达对象、状态、操作及必要限制。沿用共享按钮与表单控件。

快捷生成区以参考素材、连线文字和本次描述为主体。底部集中模型、输出参数和生成按钮，更多参数按需打开。桌面工具栏与侧边栏使用图标，窄屏将模型与生成操作分行。
