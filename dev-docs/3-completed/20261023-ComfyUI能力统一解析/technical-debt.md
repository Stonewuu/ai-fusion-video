# 维护边界

- 历史模型 JSON 没有记录自动填入与手工编辑的来源。为保留用户限制，不猜测删除已有数量上限；界面显示现有约束并允许管理员明确选择跟随工作流。新配置不再自动填入能力值。
- 历史冻结任务没有新快照标记。读取服务器持久化快照时显式标记，避免按当前发布版本重新解释旧任务；不接受客户端伪造快照状态。
- 固定图片绑定与 string_list 字符串列表语义不同。本轮不增加通用图片数组上传或自动修改工作流图结构。
- 真实 GPU 生成验证未执行；自动回归覆盖解析、校验、接口序列化、原有 ComfyUI 请求准备与版本固定，不把本地合成响应的页面验收当作 GPU 生成通过。
- 发布工作流的标量参数仅识别已绑定字段；尺寸、时长等数值限制沿用明确配置，不根据任意自定义节点猜测范围。字符串列表未声明上限时保持未设上限语义，不推断节点具备图片批次处理能力。
- 本轮未增加数据库迁移、能力副本、后台同步、图连线推理或自动扩槽。工作流内部自定义节点与输出关系仍由现有验证和发布前试运行确认。
