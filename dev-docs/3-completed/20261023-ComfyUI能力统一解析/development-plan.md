# ComfyUI 能力统一解析

## 设计边界

- 已发布工作流是 ComfyUI 生成输入能力的来源。模型只保留关联、运行参数和使用限制，不复制能力、不双向同步、不自动扩槽。
- 后端统一解析实际绑定、数量、输入类型和可用字段，前端模型列表、工作台、画布及 Agent 使用同一解析结果。
- 新任务同时固定工作流版本和解析后的模型配置；既有排队任务与画布冻结计划继续使用原快照。
- 不根据自定义节点名称猜测图片数组、尺寸或时长能力；只依据显式工作流绑定及已有数值约束。

## 实施顺序

1. 增加工作流能力解析与使用限制计算，验证版本归属、发布状态和绑定完整性。
2. 接入模型能力服务、对外模型响应、画布目录、Agent 与任务快照。
3. 删除前端选择工作流时复制能力的逻辑，展示后端解析结果并提供使用上限与“跟随工作流”。
4. 验证版本变化、限制保留、没有来源标记的历史配置、不可用工作流、前后端一致性；完成界面验收。
