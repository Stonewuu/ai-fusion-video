# 交付结果

ComfyUI 生成输入能力统一来自已发布工作流。模型保存关联、执行参数和使用限制；工作流发布后，新查询按新版本解析，已有任务继续使用原快照。没有双向同步、自动扩槽或独立能力表。

## 关键实现

- `ComfyUiWorkflowCapabilities` 根据已发布版本的显式绑定解析输入字段、固定索引覆盖、输入上限和提供输入时的最少数量。固定槽位不连续、版本归属错误、未发布版本和限制冲突明确报错。
- `GenerationModelCapabilityService` 是模型响应、Agent 与提交校验的共同入口。Agent 一次响应只解析一次版本；接口正确保留列表上限的 JSON null。画布按所选发布版本使用相同输入及参数，并独立标记冲突版本。
- 任务与画布计划冻结解析结果及工作流版本，恢复服务器历史快照时不按当前发布版本重新计算。能力解析后发布了新版本，也不会更换本次任务版本。
- 前端删除选择工作流时回写能力的行为；提供可选使用上限和“跟随工作流”，显示发布版本。模型列表与生成工作台消费后端计算结果，解析失败时明确不可用。固定入口缺项和多余输入在提交前检查。
- 模型保存也进行后端校验。前端不清洗或重写 ComfyUI 原始限制 JSON，避免无效输入被静默变为空配置；校验中的表单保留字段位置，正常失焦不会吞掉第一次保存点击。

## 验证

- 86 项后端测试通过，覆盖跨入口能力一致、发布变化、旧版本/历史快照、列表限制、禁用限制、冲突隔离、版本错配、非法策略、总图片上限和固定输入不足；原有四图逐槽准备、ComfyUI 图片/视频策略及 Agent 测试一并通过。没有发起真实上游生成。
- 79 项前端测试通过，新增后端结果优先、解析失败不采用旧能力、列表无上限语义、工作台数量检查与画布版本约束的回归；类型检查和本次修改文件的 ESLint 通过。
- Chrome 验收实际业务组件在桌面和 390px 窄屏的明暗主题、错误/禁用/聚焦状态；长表单顶部、底部和中间输入可达，窄屏无横向溢出，末项保留焦点外圈空间。此项使用本地合成接口响应。
- 本地后端正常启动，Flyway validate 通过 65 条已有迁移；新能力接口出现在 OpenAPI，前端与后端 HTTP 可用。

## 保留边界

历史配置无法区分自动填入与用户手工设置，因此保留已保存的约束，由用户明确解除。尺寸、时长等标量限制不从任意自定义节点推测；本轮不增加通用图片数组上传、自动扩槽或工作流内部连线分析。真实 ComfyUI GPU 生成尚未执行。
