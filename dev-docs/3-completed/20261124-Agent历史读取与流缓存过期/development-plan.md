# Agent 历史读取与流缓存过期

状态：2026-11-25 已完成实现、自动化测试和 Chrome 验收，代码位于 `feat/agent-redis-stream`，尚未发布。

智能助手和 Pipeline 统一从 MySQL 重建已保存的消息，再读取 Redis 中尚未保存的草稿和后续增量。整轮父子任务结束、消息提交后，流及配套索引保留 24 小时；运行和等待确认期间不过期。状态查询和过期后的历史读取不得重新创建 Redis 流。

实施范围：共享历史快照与增量读取协议、父子任务结束后的缓存期限、两种前端消费方式、取消后的消息与状态保存。

验证覆盖普通对话与多子 agent 对话：执行中关闭页面再打开、关闭后结束再打开、取消后再打开、子任务运行和取消状态、模拟缓存到期后查看历史并继续发送消息。保留权限、消息顺序、归属、去重和旧协议回归验证。
