# 权限边界二次实证审计

状态：已完成（2026-10-23）。以用户最新要求为准，停止新增攻击式复现，采用代码审查和本地回归完成修复。

## 判定标准

- 只将隔离环境中真实请求成功读取、修改或删除无权资源的结果认定为越权漏洞。
- 源码疑点先建立有效业务数据、合法访问对照和拒绝访问预期；修复前保留失败回归与实际结果，修复后复测相同路径。
- 正常团队共享、显式画布授权和所有者权限不作为漏洞；不能复现的疑点不写成已确认问题。
- 隐藏 bug 按实际业务结果确认，区分认证/并发问题与对象越权。

## 范围

检查项目及子资源、画布协作与历史、导出/模板/媒体、生成任务、AI 对话与运行、个人 Skill/MCP、账户与会话，以及已修改流程的合法访问。

## 步骤

1. 枚举当前入口并追踪真实授权链。
2. 在临时数据库与本地服务建立可复现的 HTTP 回归。
3. 只修复经验证的问题，保留用户已有工作区改动。
4. 运行针对性回归，说明已验证及未验证范围后归档。
