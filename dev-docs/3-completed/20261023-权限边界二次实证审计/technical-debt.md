# 遗留与限制

- 本轮确认的 1 处对象越权及 4 个业务/会话 bug 已修复，无本轮已确认而未修复的问题；修复保存在工作区，尚未发布或部署。
- 用户要求减少攻击式操作后，没有再增加攻击式复现；后续使用源码追踪、修复后的回归，以及成员重新添加等正常流程测试。未访问线上用户数据，生成服务使用本地受控测试提供商。
- 图片生成任务撤权后的删除通过真实 HTTP 完成修复前后对照；视频与 AI 工具采用相同的服务层权限边界，本轮没有再单独制造视频或 AI 攻击场景。不得将它们计作多处已独立复现的漏洞。
- 前端跨标签页协调通过单元测试验证会话变化；本轮没有真实浏览器多标签页端到端验收。普通 HTTP 与 SSE 均接入同一协调器，类型检查通过。
- 复核范围是本文列明的权限链与状态流转，不是对所有依赖、所有网络部署或整个代码库作无漏洞保证。来源 URL、代理及外部 MCP 网络行为未追加网络攻击验证，不列为已确认漏洞。
- 不把正常团队共享、显式画布授权、无数据变化的成功响应或存在下游权限检查的控制器认定为越权。
