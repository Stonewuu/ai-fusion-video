# 遗留事项与边界

- 本轮确认的问题已修复，未引入兼容 fallback，也不需要数据库迁移。
- 修复在当前开发工作区；运行旧发布版本的部署仍需升级。当前工作区包含大量既有重构，不能把本次几个文件直接视为独立适用于 v1.2.0 的补丁。
- 若旧接口曾对非管理员开放，部署后应按实际账户和访问情况检查团队/项目成员与角色，并轮换可能暴露的模型 API、应用、代理和邮件凭据；本轮未读取生产密钥、改动线上权限或代为轮换凭据。
- 核查包括版本源码、主要对象授权调用链及隔离环境的真实 HTTP/数据库测试。未做线上攻击、历史入侵取证、第三方依赖漏洞库扫描或全部功能的渗透测试，不能据此宣称整个项目不存在其他漏洞。
- 同团队成员可按现有产品策略读取团队及团队成员的项目；公开注册固定加入默认团队。本次保留该共享策略，验证独立个人身份、不同团队和显式项目角色的边界。
