# 开发计划

在 v-1.3.1 继续完成分镜读取、排序和媒体生成等待的修复。

- 整份分镜查询只返回集、场次、版本和数量；查询镜头必须指定一集，单次最多一整集。场次查询保留现有能力，禁止跨集数组或全量镜头开关。
- 镜头数量直接聚合查询，避免读取全部镜头正文再删字段。同步调整主调度器提示词与工具结果展示。
- 新建分镜集默认以集号作为排序值，避免并行完成先后影响顺序；保留集合命令手动排序，不改动其他集的版本。
- 按模型配置容量调整长文本读取和直接返回预算，保留完整结果、会话隔离、内容版本与 Unicode 字符位置。
- 普通资产和分镜生成使用持久化等待；恢复读取仍验证用户和项目范围，画布节点保持节点范围校验。提交中不得判为失败或重新提交。
- 前端区分已受理、等待中、完成、部分完成、待核实，显示生成输出。

验证包括查询边界和权限、乱序创建与手动排序、长文本预算、等待暂停与恢复、数据库聚合查询和前端构建。不为验证新增付费生成请求。
