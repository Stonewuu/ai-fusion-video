# 技术债务与边界

- 字符预算不是 token 精确计量：读取预算为模型配置上下文的八分之一，最多 64000 字符；直接返回阈值为其两倍。未配置上下文时每次读取最多 8000 字符。整段请求仍由内核的上下文压缩策略管理。
- 不提供整份分镜镜头详情的兼容开关。需要镜头内容时必须限定一集或一场；调用方提示词随协议同步调整。
- 原始生成结果未知或需要核实不等于失败，不通过重新生成掩盖供应商状态未确定的问题。
- 等待使用现有外部执行持久化协议；等待时 owner 已释放，后台读取携带原运行身份和范围，不构造可写入的智能体租约。业务写回只在恢复运行后执行。
- 不修改已生成分镜内容、已有排序或用户的模型配置。未发布，不新增数据库迁移。
- 工具协议版本提升为 afv-tools-v4；旧运行的工具快照不静默改写。已结束的历史任务保留当时的结果，更新不会自动重新生成或回填历史任务。
