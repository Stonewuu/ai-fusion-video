# v1.1.2 发布计划

## 目标

- 将前后端产品版本更新为 `1.1.2`。
- 发布 Pipeline 历史记录与平台客户端错误兜底修复。
- 完成验证、提交、推送并创建正式 GitHub Release。

## 发布范围

1. 修复历史 Pipeline 子工具结果缺少调用投影或投影乱序时的时间线重建异常。
2. 修复字符串化 JSON 被文件路径脱敏规则整段替换，以及普通文本结果无法安全查看 JSON 的问题。
3. 增加全平台客户端错误隔离、恢复面板和顶部错误提示。
4. 统一过滤请求取消、Next.js 内部控制流和自动 Token 续期错误。
5. 更新 Maven 项目版本、SCM tag 和前端包版本为 `1.1.2`。

## 验证

- 前端 TypeScript、ESLint、Node 测试和生产构建。
- 后端相关单元测试及 Maven 打包验证。
- 真实历史 Pipeline 浏览器回归。
- Git 差异与提交范围检查。
