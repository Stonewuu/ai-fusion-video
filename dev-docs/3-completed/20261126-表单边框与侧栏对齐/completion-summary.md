# 表单边框与侧栏对齐

独立输入框、下拉框、分段选择、上传入口和组合输入使用主题的输入边框色。组合输入由外框绘制边线，聚焦时保留外圈，校验错误显示错误色。画布输入框和模型选择器沿用画布的尺寸和底色。

素材资产的项目筛选、搜索和视图切换统一为 36 像素高。窄屏下项目筛选独占一行，搜索和视图切换并排。资产类型筛选增加选中标记。

项目侧栏将折叠按钮放在“返回项目列表”右侧。项目名称及说明使用独立区域，较长时省略显示。收起后按钮和导航图标居中，键盘可直接再次展开。

普通页面的折叠按钮在菜单标题右侧。剧本和分镜目录把刷新、折叠放在分集数量右侧，手机端在同一行关闭目录。资产目录和工作流目录的操作与标题对齐，数量单独放在下方。助手会话和运行任务的状态图标与第一行标题对齐，第二行放状态和时间等信息。

## 验证结果

- 在本地生产构建中使用 Chrome 核对素材资产、项目、通用设置、API 配置、剧本导入和画布生成节点。浅色和深色主题下，截图中三项控件各自的常态边框均为同一颜色、1 像素。
- 桌面侧栏顶部两个按钮均为 36 像素高。六个导航项的文字与图标中心偏差均为 0 像素。收起后的图标水平居中，移动端抽屉的返回按钮和导航文字也垂直居中。
- Chrome 逐页测量了仪表盘、项目列表、素材资产、画布列表、生图、生视频及 6 个系统设置页面。12 页的标题与折叠按钮、菜单图标与文字的中心偏差均为 0 像素。
- 分镜目录折叠按钮和资产目录刷新按钮原先分别比标题中心低 6 和 9 像素，调整后中心偏差均为 0。用键盘收起、展开包含 46 集的剧本目录，焦点保留在原按钮，列表回到原滚动位置。
- 长项目名曾将“打开分镜详情”挤到手机屏幕外。工作区较窄时，目录和详情入口分别在标题行两端，生成、合成和视图操作另起一行。用 320、390、768、1280、1600 和 1920 像素宽度复测，按钮均在工具栏内。
- 在画布编辑器中分别打开左右面板，32 像素的关闭按钮与标签组对齐。另检查了工作流目录的新建按钮、助手会话的删除入口，以及任务列表的状态图标。
- 长弹窗首项和末项获得键盘焦点时保留了完整的 3 像素外圈。剧本分集字数无效时显示错误边框，未配置模型时助手输入区保留组合外框并显示禁用态。
- 前端回归测试、TypeScript 和生产构建通过。此项改动已随 v1.4.3 上线，线上已核对素材资产工具栏和项目侧栏。
