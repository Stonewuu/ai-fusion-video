# 开发计划

按照 Google 官方模型目录逐项核对 Gemini 预设，并加入 Models.dev 联网搜索与手动匹配。补齐模型标识、输入输出能力、上下文和思考配置，以及图片比例、分辨率、参考图限制。复用 v-1.3.1 分支，保留现有修改。

1. 核对 Gemini Developer API 与 Vertex 官方目录和单模型说明，记录来源与核对日期，区分当前模型、历史模型和平台尚未接入的类型。
2. 补齐可调用模型的官方预设，分离 Flow 同名渠道预设，确保按渠道和完整模型 ID 匹配。
3. 修正远程发现分类、预设匹配以及能力参数传递中与官方规格不一致的部分。
4. 验证预设载入、精确匹配、图片尺寸和思考参数；通过 Chrome 检查当前 Vertex 模型使用正确预设。
5. 接入 Models.dev 公开目录、缓存、模糊搜索、预览和用户主动应用；保留 Flow 等渠道预设及手动配置，不自动覆盖已保存模型。
6. 将用户要求的产品文案规范写入全局 AGENTS.md，覆盖所有项目和功能；本轮不新增实时语音／嵌入执行器。
