# 边界与待确认事项

- 官方目录包含实时语音、语音合成、嵌入、转写、托管研究智能体和视频生成。预设数据不能替代调用接口的接入；平台未支持的能力应明确记录，不能伪装成普通对话模型。
- Gemini Developer API 与 Vertex 在生命周期、模型代码、地域、输出上限等方面可能不同；记录来源并按渠道匹配，不按名称相似度自动替换。
- Flow 现有预设及持久化引用需要保留兼容。新增官方预设采用独立标识，不改写历史预设含义。
- 模型目录里没有公开确认的参数不猜测；来源冲突需要记录，不能静默合并成看似完整的能力。

## 本轮实现边界

- Models.dev 提供通用能力；图片比例、尺寸和参考图上限由经过官方核对的本地 Google 预设补充。匹配不会替换用户的调用 ID、API 渠道、请求协议或并发设置，原有配置覆盖项继续保留。
- Models.dev 未给出的通用字段保留当前值，界面预览显示“—”。新启用的多模态输入沿用现有表单的 Base64 默认传输方式，已有传输选择保留，用户可继续编辑。
- Models.dev 的最大输出和工具调用属于目录信息，平台没有对应独立模型字段；目录来源保存在 config.catalogMatch，不将最大输出直接设为每次生成的默认输出预算。
- Google 官方目录中 Live、TTS、Embedding、Transcribe、Omni 视频和托管研究智能体没有进入本轮可执行预设；对应调用协议尚未接入。已停用的旧型号不增加新的可用预设，保留现有 Flow 别名的历史用途。
- Gemini 4 的 1M 长输出依赖连续解码；本轮按同步/流式单次输出上限记录 65,536，未实现长输出续传。模型上下文总窗口仍为 1,048,576。
- 官方图片文档将 Gemini 3.1 Flash Image 的 512 档 21:9 列为 792×168，与该比例不一致。本轮保留来源原值并按用户显式选择的比例与档位发给 Google，不通过像素反推改写比例；该组合未作付费验证，后续应随官方修正更新。其余档位采用官方尺寸表。
- 保留历史任务及工具只传宽高的使用方式：没有显式比例/档位时按宽高识别；新任务的比例和档位原样传递，避免把 1:8 的 1K 图片误当 2K。
- Gemini Developer API 图片接口复用已验证的 Gemini 内容格式并使用独立 API Key 地址；本轮未借用 Vertex Key 调用 Developer API，也未启用或修改 Google Cloud 服务权限。
