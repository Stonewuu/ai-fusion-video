# Redis 流式与消息持久化

分支：feat/agent-redis-stream。范围以《Redis流式回放与完整消息持久化方案》及用户后续确认执行：正常运行不丢消息，Redis 保存增量，MySQL 保存完整消息和工具记录，不新增 Redis 主动删除、裁剪、过期或异常退出恢复机制。

## 实施安排

1. 引入运行的存储协议版本，旧运行保留原 MySQL 事件读取；新运行使用 Redis Stream。远端最新正式版本和 Tag 已核对为 v1.4.1，新开发版本使用 1.4.2。
2. 完整消息按稳定身份保存，合并同批消息计数更新；流式序号由 Redis 管理，不再逐片更新运行表。启动、审批、外部等待和终态仍可靠保存。
3. 调整流读取、工具参数/结果读取、父子运行展示及完成判断。前端明确识别新协议，处理完整消息替换和重连去重。
4. 运行迁移命名、后端集成、前端协议测试及构建，再通过独立测试实例复测消息与工具调用，并比较 SQL 次数。

## 验证重点

覆盖长流超过 200 条、消息/工具参数/结果完整保存、断线重读、并行子任务、暂停/批准/拒绝/取消、历史运行兼容以及完成通知发出前消息已提交。保留原有权限、租约和业务幂等语义。
