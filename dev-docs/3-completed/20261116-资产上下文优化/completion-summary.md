# 完成情况

## 最终行为

- `list_project_assets` 默认每页 50 个主资产，支持项目、类型和名称筛选，返回 ID、版本、名称、类型、最多 200 字符的描述摘要、子资产数量及图片状态；不加载完整属性、提示词或子资产正文。
- `query_asset_items` 默认每个主资产每页 20 个子项，返回各主资产独立的页码、总数、`hasMore` 与 `nextPage`。按名称查询仅返回主资产候选；确定 ID 后再读取子资产目录。
- `get_asset_item` 返回一个子资产的完整设定、媒体地址及当前子项/父集合版本。原有 `get_asset` 保留单个主资产完整详情。
- 生图、分镜、资产提取及自定义智能体通过统一依赖补齐详情工具，按摘要筛选后读取所需对象。
- 创建、修改和批量写入的工具回执保留对象标识、版本与摘要，持久化审计回执仍保留完整数据。
- 执行记录同时展示总数与本页数量，并继续支持既有历史回执。
