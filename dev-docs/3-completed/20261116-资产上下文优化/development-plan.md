# 资产上下文优化

## 范围

资产与子资产工具先查询分页摘要，选中对象后再读取完整设定；写入回执避免重复携带长描述、属性与提示词。保留原有工具结果分段读取能力。

## 实施

1. 增加主资产和子资产摘要 SQL，沿用项目与个人、团队授权范围，并返回稳定排序、当前版本、总数和翻页信息。
2. `list_project_assets` 支持名称筛选；`query_asset_items` 按名称返回主资产候选、按 ID 返回子资产摘要。新增 `get_asset_item` 读取单个子资产完整详情。
3. 自动登记摘要工具需要的详情工具，更新生图、分镜和资产提取提示词。
4. 写入回执投影为摘要，保留持久化审计内容；执行记录明确显示总数与当前页数量。
5. 验证分页权限、单项详情、版本、回执不可变和前端展示代码。
