# 维护边界

## 历史执行记录

持久化的旧 `query_asset_items` 回执使用 `assetName`、`assetType`、`totalItems`，新回执使用 `name`、`type`、`itemCount`，并增加分页元数据。结果组件同时读取两种字段，旧记录缺少页码时不展示分页信息。此兼容仅用于历史执行记录展示，不改变新工具接口，也不为后端查询失败补造数据。

## 查询与全文

摘要中的 `descriptionPreview` 不能代替完整设定。图片提示词、完整属性与图片地址通过 `get_asset` 或 `get_asset_item` 按需读取。单个对象异常长时仍使用已有分段读取工具，不在这里截断完整详情。

未新增数据库结构和迁移，未调整工具分段读取实现。
