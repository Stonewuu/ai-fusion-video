# 分镜表格列宽与编辑布局

2026-11-10 在 v-1.3.1 工作区完成，本地已生效，尚未发布。

## 最终行为

增大景别、时长、摄像机角度、运镜及正文列的默认宽度，设置可用的最小宽度。短字段单行显示，长正文自然换行。单元格在悬停或键盘聚焦时显示淡色背景和小圆角细边框，不再显示铅笔；整格可点击编辑，并保留点击编辑提示。

旧列宽记录中未调整的默认值应用新布局，用户调整的宽度在新最小值以上保留。新保存记录包含版本，避免再次读取时误判用户设置。列定义和存储处理从表格组件中拆出。

## 验证

当前项目“远景”“10”“随陆阳视线摇向后方”均完整显示一行。悬停前后正文宽度和位置一致。列宽拖动时表头、正文保持对齐，刷新后宽度保留；项目分镜内容没有改动。

隔离页面验证普通保存、取消、失败草稿保留、重试、提交期间禁用、多行保存和深色窄屏焦点。六项列宽兼容及横向滚动回归测试通过，生产构建和 TypeScript 检查通过。

## 保留的边界

表格使用横向滚动，仍可手动调整列宽；短字段过长时显示省略号并通过悬停提示提供完整值。旧数组无法区分用户主动设回旧默认值与未调整状态，升级范围和处理方式已记录在 technical-debt.md。
