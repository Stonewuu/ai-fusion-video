# 兼容范围与验证边界

已有 `fusion-storyboard-col-widths` 使用 14 项数组，记录包含用户拖动宽度及未调整列的旧默认宽度。本次明确兼容这一格式；以后保存为带 `version: 2` 的记录，避免新设置刚好等于旧默认宽度时被误升级。历史损坏记录与浏览器存储不可用保持原有显示行为，存储失败记录到开发日志。

表格保留横向滚动与手动调整列宽。超出短字段列宽的内容使用省略号，悬停查看完整值；分镜内容和对白完整换行显示。页面布局验证不修改模型配置或业务内容。

旧数组没有逐列记录“是否被用户调整”，所以只能按是否等于旧默认宽度识别未修改列；若用户主动设回相同数字，也会应用新默认宽度。版本 2 不再使用这一识别规则。窄列中的保存重试操作允许换行，避免超出单元格。
