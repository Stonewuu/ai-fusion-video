## 问题与处理

React Flow 的连线容器带有阻止平移的 `nopan` 标记。此前只启用了移动模式的左键平移，没有调整连线的鼠标响应，因此从连线上按住拖动仍会被拦截。

编辑器现在通过现有移动模式及 React Flow 的空格按键状态标记正在平移。对应样式让连线、标签和重连手柄不再接收鼠标事件，由底层画布处理拖动。该样式同时覆盖普通连线与辅助连线，结束移动后自动恢复。

## 修改范围

- `components/canvas/editor/canvas-flow.tsx`：提供移动状态标记，支持移动工具和空格临时移动。
- `components/canvas/editor/canvas-flow.css`：移动期间将连线区域的鼠标事件交给画布。
