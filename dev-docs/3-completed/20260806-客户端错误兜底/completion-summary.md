# 完成总结

## 最终范围

- 为整个平台增加客户端错误隔离，覆盖 Dashboard、登录等外部页面以及根布局最终兜底。
- Dashboard 内分别隔离当前路由、顶部导航、桌面/移动侧栏、AI 任务中心、版本提示和融光助手，单个区域异常不再拖垮整屏。
- 对未捕获脚本异常和未处理 Promise 拒绝统一显示顶部居中 Toast。
- 统一全局监听与 API Toast 的忽略策略，不提示请求取消、Next 内部控制流和自动 Token 续期失败。

## 关键实现

- 使用 React 错误边界与 Next.js `error.tsx` / `global-error.tsx` 提供可操作恢复面板，支持重试和返回仪表盘。
- AI 任务中心自身异常时自动关闭面板并保留平台其余区域，同时显示顶部错误提示。
- HTTP 与 SSE 自动续期失败使用明确的认证流程错误码，不依赖固定中文文案；认证跳转仍按原流程执行。
- 可忽略错误会阻止浏览器生成未处理错误噪声，普通业务与渲染异常仍保留提示和控制台诊断信息。
