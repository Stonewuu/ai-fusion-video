# 开发计划

## 目标

避免客户端渲染异常进入 Next.js 默认白屏，并通过页面顶部全局提示告知用户。

## 实现范围

1. 为 AI 任务中心增加局部错误边界，异常时关闭面板并保留当前页面。
2. 分别隔离 Dashboard 内容、顶部导航、侧边栏、版本提示与融光助手。
3. 为根应用内容增加统一客户端错误边界，覆盖登录页等 Dashboard 外页面。
4. 增加 Dashboard、根路由和全局错误页面，提供重试与返回仪表盘操作。
5. 监听未捕获错误与未处理 Promise 拒绝，统一使用顶部 Toaster 提示。
6. 统一全局监听与 API Toast 的忽略策略，过滤请求取消、Next 内部跳转和已接管的 Token 失效/刷新流程。
7. 为 HTTP 与 SSE 自动续期错误增加明确错误码，避免依赖后端返回文案判断。

## 验证

- TypeScript 类型检查。
- ESLint 检查。
- 前端回归测试。
- 本地浏览器正常页面与任务中心回归验证。
