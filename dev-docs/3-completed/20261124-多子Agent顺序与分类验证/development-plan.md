# 多子 Agent 顺序与分类验证

在 `feat/agent-redis-stream` 分支启动本地环境，使用用户指定的拓元渠道，核对渠道模型列表后配置 `DeepSeek/DeepSeek-V4.1-Flash-1017`。

同一轮对话要求父运行并行委派三个独立分集。核对执行时间是否重叠、事件序号是否递增、每个子运行的文本/思考/工具调用/结果归属是否正确，以及断线续读和完整消息替换是否重复或串组。使用收到的事件验证对话与运行通知两处时间线，并在 Chrome 检查最终展示。

本地服务保留运行，前端端口 3000、后端端口 18081，使用现有本地 MySQL/Redis。18080 已被其他项目占用，不调整该进程。
