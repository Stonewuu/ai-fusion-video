# 全站表单边框与焦点可见性

## 目标与范围

逐一排查应用页面、Dialog、Sheet、Popover、画布侧栏和行内编辑中的表单布局，保证边框、圆角、错误状态和焦点外圈完整可见。以用户提供的“重新解析剧本”截图为已确认问题，范围覆盖全站，不局限该弹窗。

## 实施与验收

1. 将四边留白、标签间距、滚动容器与焦点检查要求加入根 AGENTS.md。
2. 静态盘点全部表单控件与裁切祖先，逐项分类，修复无安全内边距或不正确滚动层的使用处；不修改 components/ui。
3. 通过 Chrome 实际检查原问题及各类页面/弹窗/抽屉中的聚焦、校验、禁用、滚动顶部/底部；覆盖桌面和 390px 窄屏。
4. 对实际修改运行 TypeScript、ESLint 和相关已有测试，更新本地构建；记录截图、控件覆盖及尚无法实测的条件。

禁止用取消焦点环、边框内缩或负 margin 隐藏问题。测试不提交剧本解析、生成、邮件、密码或存储迁移等实际副作用。
