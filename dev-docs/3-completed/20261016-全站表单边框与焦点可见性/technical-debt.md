# 边界与待闭合事项

- 不改共享 components/ui；使用业务共享滚动容器及各表单布局提供焦点安全空间。
- 静态祖先分析只用于定位风险，不能替代渲染后的聚焦和滚动验证；依赖数据或权限的未显示状态须单独记录。
- 保持现有输入/保存业务行为；不为界面验证发起生成、重解析或其他外部副作用。

## 本轮验证边界

- 运行记录中的失败恢复、审批、写回、候选结果等依赖特定任务状态。本轮对这些组件及其 DialogScrollBody 调用链做源码审查，未为展开全部条件分支而制造供应商请求。不能把本轮结果表述为所有数据组合的穷尽测试。
- 注册功能当前关闭，只完成注册表单源码检查；没有为验收修改注册权限或创建账号。找回密码未发送邮件，密码字段未填入凭据。
- 额外计划的 390px 全属性资产创建弹窗受 Chrome 扩展界面占用影响，未取得最终截图；同一表单桌面 14 项、明暗窄屏解析弹窗和窄屏 ComfyUI 已完成。此项不计入已通过覆盖。
- 浏览器字段几何审查只提供线索：固定定位浮层不一定受普通 DOM 祖先 overflow 裁切，禁用离屏控件也不能据此判定边框错误。原始结果和人工分类同时保留，不能直接将几何告警数量当作缺陷数。
- 独立构建目录通过 Junction 共用 node_modules，Turbopack 因根目录外链接限制失败；使用 Next.js 支持的 Webpack 构建完成生产编译，不向产品加入兼容或 fallback 代码。
