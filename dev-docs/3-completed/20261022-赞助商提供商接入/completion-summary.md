# 赞助商提供商接入交付总结

完成日期：2026-10-22。交付范围：秘塔 AI、无限星河 AI 的对话、图片、视频接入，以及统一的赞助展示和快速配置。

## 设计结果

提供商目录 → 多个 API 配置 → 各自模型 → 显式请求协议。赞助是提供商的展示资料，独立于配置能力和运行协议。现有提供商、自定义接入和赞助平台共享配置及执行链路；取消 sponsored 不影响 quickSetup 或已有调用。

新增赞助商优先增加目录定义、发现映射和已核实的能力预设，仅对真实协议差异增加适配器。AFF 统一替换目录中的 credentialUrl，2026-10-23 已换为用户提供的两家推广入口。

## 用户可见行为

- 选择平台 → 自动填地址 → 填密钥 → 读取并勾选模型 → 一次保存。后续追加复用已保存密钥，已有模型禁选且保留用户设置。
- 秘塔默认地址为 `https://metaso.cn/api/minimax`，无限星河为 `https://infistar.cc`；常见固定地址平台同样自动填写。万相 3.0 提示填写所属业务空间地址。
- 秘塔仅显示三个已核实的视频型号，H3 支持独立 Context IR、优先通道开关，默认关闭。
- 无限星河根据账号权限和明确接口筛选类型，使用平台独立参数预设。未知参数候选可转入预填的手动表单；未适配输出协议不错误归入对话。
- 导入无密钥配置时先停用并保留模型，可在列表补充密钥后启用。错误和加载状态明确，失败不伪装成空列表或成功。

## 关键实现

- 后端统一目录和 providerId 绑定；迁移 V1.1.3.0.37 增加平台身份、请求幂等字段及唯一约束。
- 发现与外部请求在事务外执行，最终保存使用短事务；保护管理权限、并发去重、整批回滚及旧配置不被覆盖。
- 秘塔复用 MiniMax V2；无限星河复用文本、Images 和异步视频执行链路，显式声明鉴权、文件字段、任务 ID 及平台能力差异。
- 网络连接恢复只用于 GET；收费 POST 保持单次交换语义。
- 前端复用平台选择、赞助说明、候选搜索/类型筛选、批量保存、手动预填及开关组件；未修改共享 UI 基础组件。

## 验证结论

独立数据库迁移与 Flyway validate、真实事务及权限测试、协议 HTTP 合同、缓存、单次请求语义、前端规则测试、TypeScript、组件 ESLint 和生产构建通过。用户明确授权的本轮内置浏览器验收覆盖新增/追加/导入修复/手动预填、默认地址、明暗主题、桌面和窄屏、长内容滚动、焦点、校验错误及禁用状态。

首次验收时，真实密钥经两家默认地址各完成一次只读预览：秘塔验证成功并提供 3 个视频预设；无限星河筛出 204 个候选，其中 197 个可快速添加、7 个需补参数。数量随账号权限和平台目录变化。该阶段未发起收费生成，生成链路由本地 HTTP 合同测试验证。

2026-10-23 按用户追加授权完成真实文字、图片和两家视频调用，全部成功保存；同时修复大体积图片结果阻塞共享任务队列的问题。具体模型、实际输出及一次线路拒绝见相邻需求目录「20261023-赞助商真实调用验收」的完成说明。

同日下午追加验证无限星河 Seedance 2.0 Fast 和 MiniMax H3，均成功保存并通过文件和画面检查；可灵 2.5 Turbo 被平台分组限流拒绝，没有重复调用。详情见相邻需求目录「20261023-无限星河多模型真实验收」。
