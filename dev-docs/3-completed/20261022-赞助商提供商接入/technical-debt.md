# 技术债务与维护边界

本次范围已完成。以下记录协议兼容对象和维护边界，避免以猜测或静默降级扩展能力。

## 平台协议

- 无限星河 Models 不保证完整能力元数据，因此与同源模型广场的精确 ID、接口声明和输出标签取交集；结构缺失报错，未知接口不按名称猜测。
- 当前图片链路支持 Images 接口。标记为图片生成却只暴露对话格式接口的模型不进入快速配置；后续须完整实现对应图片输出协议后再开放，不能当作文本模型导入。
- 无限星河维护独立图片/视频预设。视频发送 model、prompt、seconds 和适用的单张 input_reference；尺寸明确为“平台默认”并省略 size，不暴露请求无法表达的比例或原厂专属能力。
- 未核实参数范围的图片、视频保留手动预填入口；后续核实具体型号后再增加快速配置预设，不伪造未知上限。
- Videos 明确兼容 task_id 和 OpenAI 风格 id，同时出现且冲突则拒绝；单图编辑用 image，既有 OpenAI 多图合同继续用 image[]。
- 秘塔复用 MiniMax V2 内容及任务解析，路径、能力、Context IR、优先通道独立声明。再生成依赖原任务和平台额外授权，本次不作为独立模型提供。
- 原生文本网关以显式 gatewayAuthMode 声明 Bearer；连通性检查与实际单次请求链路一致。

## 配置维护

- quickSetup 表达配置能力，sponsored 仅表达商业展示；取消赞助不改变入口、密钥要求或模型协议。
- credentialUrl 为统一 AFF 替换入口，2026-10-23 已配置用户提供的推广链接。新增赞助商优先复用目录、发现、选择、保存及现有协议，仅为已确认差异增加适配。
- 兼容既有无密钥导出：导入先停用并保留模型，补密钥后启用；管理页必须显示停用项。
- 候选按请求读取当前密钥权限，不缓存权限列表；静态目录使用服务缓存，刷新候选不改写原配置。
- GET 可恢复失效连接，付费 POST 不自动重放；网络失败不更换协议或来源。
- 固定地址统一预填；万相 3.0 必须填写所属业务空间地址，不提供虚假的通用值。
