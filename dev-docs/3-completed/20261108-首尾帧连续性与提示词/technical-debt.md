# 实现边界

此次修订目标为智能体流程、提示词和现有镜头的可编辑提示词，不批量重绘现有图片。历史生成任务保留当时的请求，修订后的镜头提示词用于下一次生成。

没有图像理解工具的文本智能体只能核对输入和生成回执，不能宣称已经目视验收图片。场景与道具缺少资产图时，统一场次描述并在生成流程中复用同组基准帧；不能用别的地点或未经确认的旧图冒充缺失参考。

当前场次仍没有雨中乡道、马车及老马的独立资产图。本次没有创建资产或重绘图片；人物参考已有，场景和道具采用共同文字设定。生成模式的基准帧步骤已纳入提示词流程，尚未以付费生图任务验证这一步的视觉效果，不能承诺仅凭提示词完全消除漂移。

运行内核会固定当时的提示词和工具协议，已结束的历史任务保留原请求。新流程用于新建任务，不改写历史生成记录。
