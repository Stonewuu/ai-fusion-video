# APIXO 通道接入

在 `v-1.4.0` 增加 APIXO 赞助商通道，提供商入口排在无限星河、秘塔、贰春之后。接入对话、图片和视频，复用现有配置保存、权限、任务持久化与结果存储流程。

## 实现范围

- 依据 [APIXO 文档](https://apixo.ai/docs)及公开模型 schema 建立独立模型预设，准确保存模型代码、协议与参数范围。
- 对话使用 `llm.apixo.ai`，分别接入 Anthropic Messages、OpenAI Responses 和 Gemini Generate Content；图片、视频使用 `api.apixo.ai` 的异步任务接口。
- 补充生成请求、任务查询与结果解析；提交前保存请求意图，状态不明时保留原任务，不重复创建收费任务。
- 补充赞助标识、获取密钥链接、品牌图标和排序；沿用现有表单与协议选择组件。
- 使用本地 HTTP 服务验证协议与状态流转，检查快速配置的保存和界面，并通过余额接口验证账户。供应商生成接口另行联调。
