# 维护与验证范围

- 对话和生成服务使用 APIXO 公布的不同服务地址，不把生成接口当作 Chat Completions 接口。
- 模型参数采用本次核对的 APIXO 公开 schema，不继承同名原厂模型的参数能力。新增模型或供应商协议变化需要重新核对预设。
- 接入现有创作流程可表达的对话、图片生成与编辑、视频生成及参考素材输入；图层拆解、声音克隆和独立音视频处理不属于本次需求。
- 密钥从用户指定的本地文件读取，不写入源码、测试夹具或开发文档。
- 2026 年 11 月 17 日补充额度后，已完成图片、视频的主要模式与参考视频输入验证；对话仍有 7 个模型返回供应商错误，详见[模式联调结果](../20261117-APIXO模式联调/completion-summary.md)。
- APIXO 对话目录未公布的上下文长度、推理选项及多模态输入能力不从原厂同名模型复制。以后扩充这些能力时，需要核对 APIXO 对应协议并验证。
- 图片和视频预设覆盖当前创作界面支持的生成方式。Flux 2 使用 Pro 模式，Veo 3.1 使用 Fast 模式；新增其他模式时需要补齐界面参数与请求映射。
