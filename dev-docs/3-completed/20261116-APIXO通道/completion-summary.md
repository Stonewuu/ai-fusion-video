# APIXO 通道与模型目录

已在 `v-1.4.0` 完成 APIXO 的对话、图片和视频接入。提供商入口顺序为无限星河、秘塔、贰春、APIXO，包含品牌图标、赞助标识和获取密钥入口。

## 模型目录

| 类型 | 数量 | 范围 |
| --- | ---: | --- |
| 对话 | 25 | Claude 8 个、GPT 10 个、Gemini 7 个 |
| 图片 | 9 | Seedream 5.5、5.0 Pro、5.0、4.5，Nano Banana 2、Pro、基础版，GPT Image 2、Flux 2 |
| 视频 | 9 | Seedance 2.5、2.5 Flash、2.0、2.0 Fast、2.0 Mini，MiniMax H3、H3 LoRA，Sora 2、Veo 3.1 |

目录依据 [APIXO 文档](https://apixo.ai/docs)与公开模型 schema 配置。快速配置使用只读余额接口验证密钥，再提供上述模型供用户选择；余额为零时仍可读取目录并保存配置。模型预设包含请求协议、比例、分辨率、时长和参考素材限制，按 APIXO 参数保存原始模型代码。

## 关键实现

- 对话根据模型分别使用 Anthropic Messages、OpenAI Responses 和 Gemini Generate Content，通过 `llm.apixo.ai` 请求；图片、视频通过 `api.apixo.ai` 创建异步任务并查询结果。
- 生成任务复用现有请求持久化、单次提交、状态查询和结果存储流程，验证任务编号、状态与结果文件地址。连接中断时保留未确认状态，不自动重复提交。
- 图片支持文生图及参考图编辑；视频按模型支持文本、首尾帧或参考素材。首尾帧保持输入顺序，提交前检查模型允许的素材组合。
- Sora 2 不显示供应商未开放的分辨率参数；支持自动画面比例的 APIXO 图片模型保留分辨率档位。已有像素尺寸模型的自动尺寸行为保持不变。
- 本次未修改数据库结构或迁移脚本。

## 首阶段验证结果（2026-11-16）

- 后端 80 项相关用例分批通过：本地 HTTP 接口验证三种对话协议的路径、鉴权与流式结果；图片、视频验证生成参数、单次提交、待处理、成功、失败及无效结果。配置集成测试验证三类模型保存、原生代码与协议保留、重复保存幂等。
- 前端 39 项相关用例通过，覆盖赞助顺序、协议筛选、生成参数及模型切换；修改文件的 ESLint、TypeScript 检查和生产构建通过。
- Chrome 验证模型目录读取与类型筛选、选择、空结果、必填校验、加载与失败状态，以及桌面和窄屏、明暗主题下的表单边框、焦点和滚动。页面验证未向用户数据库保存模拟配置。
- 独立端口启动应用成功，Flyway 校验 37 条迁移通过。
- 通过 APIXO 余额接口验证了密钥。此阶段使用本地 HTTP 服务验证对话、图片和视频请求。
