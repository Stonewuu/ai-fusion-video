# 全页面侧栏响应优化

已在 v-1.3.1 完成并在本地生效，尚未发布。本轮针对用户再次反馈的快速移动时高亮滞后重新采集性能记录，替代上一轮只做低频悬停的验证方式。

## 最终行为

侧栏菜单的颜色、背景、边框与焦点高亮立即更新，不再等待 150ms 颜色渐变。共享规则覆盖全局菜单、剧本和分镜目录、资产目录、画布侧栏及内容树、助手会话、运行记录和工作流目录。展开收起、箭头旋转、拖拽、按压、透明度动画和助手三层波纹保留。

全局菜单区分悬停与选中背景，并补充当前页语义与键盘焦点。工作流目录取消不必要的背景模糊。所有调整位于业务组件及全局样式，共享 UI 源码未修改。

## 验证结果

Chrome 已逐页检查仪表盘、项目各常用页面、画布与资产列表、生成工作台和系统设置六个页面；同时检查剧本/分镜内部目录、412 个资产的目录、画布左右面板、助手、运行记录及已配置的 ComfyUI 工作流目录。浏览器实际计算样式确认导航高亮不再渐变，收起/展开、键盘焦点、明暗主题及助手波纹正常。

同一窗口的快速鼠标移动从修改前 478 次/8.016 秒到修改后 839 次/14.019 秒，输入频率均约 60Hz。浏览器重绘记录由约 206 次/秒降至 34 次/秒，减少约 84%；样式计算耗时按时长归一减少约 92%。GPU 进程采样由 44%–51% 降至动作时间重叠样本的 28%–32%，该计数包含 Chrome 其他页面，不能等同于单独组件占用。

TypeScript、修改文件 ESLint、生产构建及差异格式检查通过。测试没有创建或修改业务数据，没有变更用户模型。画布空内容目录的验证边界已在 technical-debt.md 说明。

发现本地开发服务漏载新全局 CSS 后已重启前端，并在确认用户表单没有未保存内容后刷新原标签。前后端均保持运行，后端未重启；测试面板和主题状态已还原。
