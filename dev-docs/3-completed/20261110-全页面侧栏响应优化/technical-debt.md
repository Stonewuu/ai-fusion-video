# 验证边界

保留现有 v-1.3.1 工作区的其他修改。浏览器只使用 Chrome，原有用户标签不关闭；临时性能设置在结束时恢复。共享 components/ui 源码保持不变。

本次已经区分悬停过渡、主线程处理和绘制开销。浏览器记录来自原标签、同一视口与约 60Hz 输入，Paint 统计按采集时长归一，不作为显示帧率使用。GPU 计数器按整个 Chrome GPU 进程汇总，包含同一浏览器其他页面的开销，不能全部归因于某一侧栏，也不能外推为所有电脑的占用率。

原开发服务没有及时更新全局 CSS，重启前端后实际计算样式已验证。没有修改开发框架或添加自动重启、缓存清理守护程序；后续样式验收仍需检查浏览器计算样式，不能只看源码。

画布面板与媒体页已验证；所打开画布虽然标题带有性能测试字样，实际显示 0 个节点，不能据此宣称已经覆盖 100 节点/400 连线。剧本、分镜及 412 个资产的目录验证使用现有项目数据。本次没有增加新的兼容分支或待实现功能。
