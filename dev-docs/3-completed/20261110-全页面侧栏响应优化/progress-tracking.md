## 定位与修改

原页面为系统设置，视口 2492×1188、DPR 1.5。连续快速移动记录中未出现主线程长任务，鼠标事件处理不足 1ms；共享侧栏的 150ms 颜色过渡会让高亮落后于快速移动，并持续触发样式计算与重绘。

新增统一的 data-sidebar-navigation 样式范围，菜单颜色、背景、边框和焦点高亮立即切换，只允许透明度、transform 及独立 translate、scale、rotate 属性过渡。业务列表的外层行使用 data-sidebar-row，覆盖剧本场次、分镜场次、分集标题及画布内容树。保留展开收起、箭头旋转、拖拽、按压和助手波纹。

共享全局菜单加深悬停与选中背景，增加 aria-current 和可见键盘焦点。工作流目录去掉不必要的背景模糊。未修改共享 components/ui 源码。

逐页验证时发现开发服务更新了 React 组件，但页面仍使用旧的全局 CSS；重启前端后已确认浏览器实际计算样式包含完整的新规则。没有通过额外兼容分支掩盖开发服务的缓存问题。

## 快速移动对比

在同一个原用户标签和窗口，按每秒约 60 次鼠标移动上下经过系统设置菜单：修改前 8.016 秒共 478 次移动，记录 1647 次 Paint、样式计算 692.767ms；修改后 14.019 秒共 839 次移动，记录 469 次 Paint、样式计算 101.809ms。按时长归一，重绘次数从约 206 次/秒降至 34 次/秒，减少约 84%；样式计算耗时减少约 92%。这里的 Paint 是重绘记录，不是显示帧率。

同一 Chrome GPU 进程的快速移动采样，修改前为 44%–51%，修改后与移动动作时间重叠的样本为 28%–32%。上一轮低频移动得到的 0%–1% 不适用于这个高频交互场景。

浏览器控制曾出现批量调用超时，已恢复会话并缩小批次完成助手与运行面板复核；超时期间的数据不计入通过结果。测试主题、全局菜单与目录收起状态、助手和运行面板均已恢复；未调整模型、业务数据、浏览器硬件加速或系统代理。
