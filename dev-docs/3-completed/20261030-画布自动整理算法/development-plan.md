# 画布自动整理算法

自动整理按执行顺序和项目关系组织节点，减少交叉、过长连线和无意义留白。接入 ELK 分层布局，在 Worker 内比较确定性的候选结果；尺寸和端口使用画布已测量或已声明的几何数据。

最终方案只计算一次 ELK 层次和顺序，再比较常规收紧布局与按链路长度、节点占地平衡各层的布局，避免反复执行昂贵的分层算法。候选评分综合交叉、平均线长、占地和纵横比例，位移作为末级取舍。采用单调回归收紧层内间距并对齐相邻端口，最终使用正交搜索避让节点和标签。

锁定节点、未选中节点保持原位。分组整体移动，子节点保留相对位置；整理分组内选区时遵守现有分组边界。候选结果必须先满足固定位置、占地和执行顺序约束，再比较交叉、连线长度、占地和位移。整理后按最终位置计算避让节点的折线，保留连线标签与现有交互。

项目的包含、素材和来源关系不受显示开关影响。一次整理使用一个编辑命令，支持一次撤销。计算期间画布发生修改时丢弃结果，不能覆盖新编辑。针对分支汇合、独立链路、锁定、分组、局部选区和 100 节点复杂连线做算法回归；浏览器交互验收由用户完成。
