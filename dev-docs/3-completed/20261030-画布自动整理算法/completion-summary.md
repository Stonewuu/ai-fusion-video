# 交付结果

画布工具栏“自动整理”改为基于执行依赖和项目关系的分层布局，按节点尺寸和端口位置组织分支、汇合及独立内容。通过层内收紧和均衡分层两个候选，避免大量素材输入挤在首列，或为了减少少数交叉把画布拉成长条。

锁定节点及其所在分组保持位置，未选中节点参与约束和避让，分组保留子节点相对坐标。空间不够时明确报错，不返回部分成功结果。一次整理使用一个版本化编辑命令，保留撤销；后台计算期间发生编辑或关系变化时取消旧结果。

布局与路由都在 Worker 内执行。路径按最终节点坐标计算，并处理输入序号、关系标签和输入校验提示；保留原有点击、重连、框选和链路高亮入口。拖动期间使用实时曲线预览，停止后合并计算；没有变化时复用已完成路径。

验证通过：68 项画布回归、5 项几何回归、相关新增文件 ESLint 和前端生产构建。保留了去除素材标识的 100 节点 / 400 连线拓扑作为长期回归用例，覆盖不同媒体高度、多端口和输入序号。离线保存图计算约 0.8 秒，单独路径重算约 0.19 秒；布局约 5580 × 3328，未发现节点重叠、连线穿过节点或标签遮挡节点，重复整理位置不变。耗时使用声明尺寸，不包含浏览器绘制及媒体解码。

用户自行进行浏览器验收，当前画布数据未改动。服务端助手的独立布局工具不在本次范围内；分组内部整体重排也未引入，详见维护边界。
