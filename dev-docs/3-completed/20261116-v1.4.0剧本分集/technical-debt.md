# 维护边界

- 现有总剧本原文字段保留历史数据，用户通过导入预览整理后迁入分集；新导入不再写入总剧本原文。
- 沿用分集原文和梗概字段，不新增数据库迁移，不修改已发布迁移。
- 单集正文分段读取的位置、版本与容量算法保持不变；读取对象限定为单集，项目级读取不再提供全文入口。
- 文件导入支持 TXT、Markdown，可选择 UTF-8、GB18030/GBK 和 UTF-16 编码。2026-11-16 按用户反馈提高容量：文件 100 MiB、单次原文 2000 万字、单集 10 万字、单个剧本最多 20000 集。
- 未新增静默兼容路径。未配置模型上下文长度时使用 256K，是本次明确要求的默认值。
- 验证使用本地服务和独立验收项目。文本模型调用验证了主任务分集调度、单集解析及续跑；分镜、视频与画布执行契约使用本地模拟供应商接口完成集成测试，未为验收生成供应商视频。
