# 1.4.0 剧本分集交付

代码位于本地 `v-1.4.0` 分支，基于已发布的 v1.3.1 最新远端提交开发。前后端版本均为 1.4.0，尚未发布。

## 使用方式

在项目的剧本页选择“导入原文”，上传 TXT/Markdown 或粘贴内容，检查分集后导入。程序识别集、章、回、话、节、卷、篇等标题，支持中文数字、大写数字、全角数字、空格、Markdown 标题及中英文章节格式。卷、序章和章节组合保持顺序；重复的目录条目不生成空分集，目录文字保留在前言中。没有标题或章节过长时按段落拆分。

预览中可以改名、在光标处分集和合并相邻分集。标题重复会标注，追加时还会检查现有分集；重名不会覆盖记录。导入后的分集可以在“场次／原文”之间切换，单集原文按需加载。已有场次默认继续补齐，勾选重新解析后才会替换。历史总剧本原文可通过“导入原文 → 拆分已保存原文”迁入分集，替换前显示原有分集、场次及引用的影响。

## Agent 读取与压缩

主解析任务分页读取目录和梗概，把分集 ID 交给单集子任务。子任务边读边保存场次，完成后回写梗概和状态。项目级查询每页默认 30 集、最多 50 集，场次和对白按集读取；原文只允许读取一集，继续使用既有分段位置和内容版本协议。写入回执、画布业务输入及画布详情查询不携带原文；画布剧本的文本输出改为梗概。

所有执行入口共用 AgentScope Java v2 的 Harness 创建流程，按当前模型上下文长度的 90% 触发原生压缩，关闭按消息数量触发。未配置长度时使用 262144 token，对应阈值 235929 token。压缩后的续跑指引保留任务范围、资源 ID、内容版本、读取位置和已保存进度。

## 验证结果

- 1522692 字测试文件生成并保存 200 集，数据库中按顺序拼接后的 SHA-256 与原文件一致，总剧本原文长度为 0。追加后的三条原有分集记录保持不变。
- 长文预览响应为 10699 字符；203 集列表响应为 58639 字符且没有 rawContent，页面首次只请求当前集场次。
- 使用项目已配置的文本模型完成三集样本解析及梗概回写。首集续跑通过更新场次工具补齐资产关联，原场次 ID 保持不变，三集状态均为已解析。
- 21 项分集规则测试通过；覆盖多种标题、卷和序章、目录、百万字单行、Unicode、段落边界及无损分区校验。
- 资源命令集成、画布执行及 Agent 集成测试通过，覆盖版本冲突、重试幂等、权限、历史引用、写回及上下文投影。分镜和视频测试使用本地模拟接口。
- 画布剧本节点用例在生成运行计划前完成准备数据的事件投递，避免准备阶段的异步画布版本更新干扰业务写入断言；版本冲突检查和原有业务断言保持不变。
- 前端构建、TypeScript 检查、15 个修改或新增前端文件的 ESLint 检查及分界编辑测试通过。应用启动完成 Flyway validate，现有迁移保持不变。
- Chrome 验收完成：导入输入及编码错误恢复、分集预览与首末项、拆分合并、重名改名、追加保存和替换取消、单集原文编辑及解析、桌面和窄屏、明暗主题、焦点与禁用状态。窄屏按钮覆盖原文框、深色选中标题对比度及模型续跑缺少关联字段声明的问题已修复。

当前实现没有待完成的兼容分支；文件类型和容量范围见维护边界。正式发布仍需按项目发布流程进行。
