# 1.4.0 剧本分集

在已同步远端 v1.3.1 的 `v-1.4.0` 分支开发。前后端版本统一更新为 1.4.0。

- 现有剧本页增加原文导入：识别章节、按段落限制单集长度、预览并调整标题及分界、追加或替换导入。
- 原文按集保存。目录与梗概查询不携带原文，页面仅按需加载当前集。
- Agent 按目录调度独立的单集解析，单集解析完成保存梗概；分镜和视频使用结构化场次与摘要。保留现有正文分段读取协议。
- 标出导入预览和现有剧本目录的重复标题，提供改名入口，禁止按重名标题隐式覆盖。
- 验证标题识别、百万字无损划分、权限、并发版本、重试幂等及上下文输出；通过 Chrome 检查桌面、窄屏、明暗主题和表单状态。

依据：[按需获取上下文](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)。目录携带标识及摘要，原文仅在处理目标分集时读取。
