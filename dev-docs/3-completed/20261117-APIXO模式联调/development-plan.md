# APIXO 模式联调

账户补充额度后，从项目的 AI 配置与生成任务流程验证 APIXO。用户要求尽可能覆盖各模型的文生图、图生图、文生视频、单图生成视频、参考素材生成视频和首尾帧生成视频。

- 项目内保存 APIXO 配置和 43 个模型，保留已有提供商与默认模型。
- 对话模型逐个执行项目自带的连通性检测；图片模型验证两种模式；视频模型按已声明能力验证四种模式。
- 使用最低可用分辨率、最短固定时长和单个输出，跟踪剩余额度。已受理任务只查询原任务；明确被拒绝的参数问题修正后单独重测。
- 图片、视频必须完成项目任务持久化、供应商查询、媒体入库和读取验证，不能仅以供应商受理为通过。
- 修复联调发现的参数问题，补充有业务意义的回归测试。结果记录各模型与模式的状态、供应商错误和未验证条件。

当前测试计划包含 25 个对话检测、18 个图片组合和 41 个视频组合；视频包含主要模式的 34 个组合，以及 7 个支持参考视频输入的组合。Sora 2 未声明的首尾帧和多图参考不作为支持能力测试。
