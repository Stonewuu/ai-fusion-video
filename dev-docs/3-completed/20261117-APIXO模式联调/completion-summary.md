## 修正与回归

- Seedance 2.5 和 2.5 Flash 的单图、首尾帧模式要求自动比例。已在模型预设中设置 `frameRatio=adaptive` 和 `frameRatioMode=required`，并通过项目接口更新本次保存的两个模型配置。界面在添加首帧后只显示“自适应”，后端在提交前拦截固定比例。这与 [Seedance 2.5 文档](https://apixo.ai/docs/models/video/seedance-2-5)及 [Flash 文档](https://apixo.ai/docs/models/video/seedance-2-5-flash)一致。
- 四个被供应商拒绝的首帧组合修正后重测成功；项目保留了修正前的失败任务记录。
- 生成记录和执行详情统一显示“自适应”，不再显示参数值 `adaptive`。
- 新增的 2 项后端比例约束回归通过；前端 40 项相关用例、ESLint 和 TypeScript 检查通过。
- 59 个图片、视频文件均通过项目下载接口读取，文件长度与 SHA-256 校验值与项目存储记录一致；图片可解码，视频可读取尺寸、时长和编码信息。
- Chrome 已验证配置保存、模型目录、图片预览、视频播放、首尾帧参数恢复及自适应比例禁用状态。
- 本地后台已重新加载最新模型预设，Flyway 校验通过；页面重载后生成记录和媒体仍可读取。

## 使用条件与剩余验证范围

本地环境没有配置后端资源公网地址，因此参考输入使用本次生成素材在 APIXO 返回的 HTTPS 地址。直接引用项目媒体库中的文件时，仍需先配置可供供应商访问的后端资源公网地址。

本次没有遍历所有分辨率、时长、参考素材数量、参考音频、LoRA 参数、草稿或续写等额外选项。当前分支为 `v-1.4.0`，本次修改未提交推送，也未合并到 `main`。
