# 模型中断自动回收

## 目标

智能体模型请求中断或取消后，自动释放本地并发名额，保留远端结果未知的记录。后续会话和画布任务不再因这条未知记录等待管理员核实。

## 实现范围

- 沿用智能体运行状态、模型请求状态和并发占用字段，分别表达本地结束、远端结果和本地资源占用，不新增数据库字段。
- 请求清理时释放名额；定时检查回收失去执行者的请求及历史未知请求占用，不重发供应商请求。
- 保留远端结果未知的用量记录，迟到响应仅补记原请求证据，不恢复已结束的运行。
- 画布详情展示未知记录，画布结束判断和会话受理不再把该记录当成仍在运行。
- 智能体模型调用退出管理员待核实列表；其他具有独立供应商任务编号的生成任务继续沿用各自的查询与处理流程。

## 验证

验证断流、取消、租约失效、历史记录回收、重复清理、迟到响应、新请求受理和画布结束判断。后端使用隔离 MySQL/Redis 与测试模型，不调用付费供应商；前端执行类型、Lint 与相关回归检查，并通过 Chrome 查看任务详情。
