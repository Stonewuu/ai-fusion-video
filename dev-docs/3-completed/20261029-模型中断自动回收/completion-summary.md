# 模型中断自动回收

## 最终行为

智能体模型请求因连接异常或取消而结束本地执行时，自动释放并发名额，保留 `UNKNOWN_SUBMISSION` 表示远端结果未知。后续请求不再因未知记录被整个会话拦截，画布也按照智能体和子任务的执行状态结束，不继续等待管理员核实。

定时检查每 5 秒处理失去执行者、租约过期、运行已经结束以及历史未知请求的本地占用。已处理记录再次检查不会重复变更，正常执行中的请求继续占用名额。原请求不会自动重新提交。

## 关键实现

- 模型请求状态、智能体运行状态和本地并发占用沿用既有字段分别维护，无数据库迁移。
- 用量结算按远端证据判断，未知记录不会仅因本地名额释放而进入结算。迟到响应可以补记原调用的用量与结束证据，不恢复已结束的运行，也不释放新请求的名额。
- 画布详情返回 `unknownModelCalls` 和 `unknownModelRequestIds`，展示“远端结果未知”及可展开的原请求编号；移除人工处理按钮和对应的持续等待判断。前后端需使用本次对应版本。
- 智能体模型调用退出管理员待核实列表和人工确认流程，已有历史核实记录仍可读取。独立图片、视频、文本、音频及 MCP 任务的原有处理流程不在本次范围内。
- 保留此前菜单切换修复和用户已有的侧边菜单顺序调整。

## 验证结果

- 23 项后端相关单元测试通过，覆盖单次提交、断流、取消、画布终态和管理员处理权限。
- 71 项画布智能体集成测试通过；最终 8 项定向复核通过。使用 Testcontainers 隔离 MySQL/Redis、模拟模型和本地 HTTP 测试服务，未调用付费供应商。
- 已验证中断任务结束并保留未知记录，同一画布节点的新任务可以成功执行；历史占用自动回收，重复检查不改写已处理记录；迟到响应只更新原请求；未知用量不被提前结算。
- 前端 65 项相关回归、TypeScript、修改文件的 ESLint 和 Git 差异检查通过。
- Chrome 使用本地示例验证任务详情提示、键盘展开编号以及 390px 窄屏，无横向溢出。临时验收路由已移除。

## 生效与边界

代码已修改，尚未发布，也未重启当前开发后端。后端使用新代码启动后，历史未知模型请求的本地名额会由定时检查自动回收。

本地释放名额不表示供应商停止运行；未取得结束证据的远端结果继续保留未知状态。
