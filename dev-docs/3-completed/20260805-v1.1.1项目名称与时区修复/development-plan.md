# v1.1.1 项目名称与时区修复开发计划

## 目标

- 建立 `v-1.1.1` 开发分支并将前后端产品版本更新为 `1.1.1`。
- 在项目设置中提供项目名称编辑能力。
- 保存后刷新项目上下文，并沿用后端现有逻辑同步关联剧本与分镜标题。
- 修复 Docker 等 UTC 运行环境中新建数据固定显示早 8 小时的问题，并统一应用与 MySQL 会话时区。

## 实施范围

1. 对照 `v-1.1.0` 的版本提交更新 Maven 与前端包版本。
2. 在项目设置表单中增加项目名称草稿、变更检测、非空校验和名称输入框。
3. 将名称并入现有项目更新请求，保存成功后刷新上下文并显示反馈。
4. 在 Spring Boot Bean 初始化前读取 `app.time-zone`，默认采用 `Asia/Shanghai`。
5. 通过 Hikari 连接初始化 SQL 和 Docker MySQL 默认参数统一新会话时区，默认采用 `+08:00`。
6. 执行前端静态检查、生产构建、Compose 配置解析和后端相关测试。
