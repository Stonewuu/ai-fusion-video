## 已落地的接口契约

- `GET /api/canvases/capabilities`：节点/参数/端口声明。这是契约目录，不能据此宣称所有生成执行器已接通。
- `GET /api/canvases`：当前账号可访问的个人及项目画布，支持项目、归档状态和分页。
- `POST /api/canvases`：客户端生成小写 UUID，提交 `id/title/projectId`；相同 ID 和内容可安全重试，内容不同返回 REQUEST_CONFLICT。
- `GET /api/canvases/{id}`：文档头、图、权限和 lastSequence 的一致性快照。
- `POST /api/canvases/{id}/commands`：`requestId + operations`，最多 500 个操作；type 为 `canvas.node.create/patch/layout/bind/delete` 或 `canvas.edge.create/replace/delete`。修改必须带对应 expectedConfigVersion、expectedLayoutVersion 或 expectedVersion。
- `GET /api/canvases/{id}/events?afterSequence=...` 与 `GET /api/canvases/{id}/stream`：只读已提交事件，SSE 优先使用 Last-Event-ID；返回 SNAPSHOT_REQUIRED 时重新读取快照，禁止把 Agent Run 游标传入此流。
- 项目画布的新引用验证真实对象存在且属于相同项目；个人画布允许独立资产/子资产并检查其单独权限。已失效引用允许移动/删除，不擅自重绑。绑定中的 observed version 不等于业务写授权，业务编辑仍须单独版本检查。
- `PUT /api/project`：`{id, version, requestId, patch}`；旧的无版本平铺更新被明确拒绝。`patch.properties` 是 JSON 对象，字段缺省保持原值，允许清空的字段显式 null 清空。
- `POST /api/canvases/{canvasId}/resource-commands`：`{requestId, resourceType, resourceId, expectedVersion, patch}`；已登记 project、script、scriptEpisode、scriptScene、asset、assetItem 修改；assetItem 还须 expectedParentVersion。已增加 storyboard、storyboardEpisode、storyboardScene、shot；排序使用独立的集合命令。
- `resource.changed` 事件包含真实资源类型/ID/版本、字段名、resourceCommandId 和 eventId。投递增加画布事件序号，不修改节点位置或复制业务正文；消费者仍需按资源版本防止旧事件覆盖新内容。
