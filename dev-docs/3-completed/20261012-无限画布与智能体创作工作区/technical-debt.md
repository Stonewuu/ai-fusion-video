# 无限画布维护约束

本需求已按 1.3.0 约定范围完成。这里记录后续维护需要保留的约定，以及本轮没有覆盖的外部服务和规模范围；阶段性故障与处理经过保留在 progress-tracking.md。

## 外部服务的验证范围

- 真实文本、图片和视频已有成功记录。视频包括无限星河 wan3.0-video 和秘塔 MiniMax-H3；本次复用这两段真实产物验证画布合成、首尾帧和交付，新增模型请求为零。
- Agnes 当时的记录仍是 HTTP 503 队列已满。不同渠道的可用性以各自实际调用结果为准，本需求完成不代表每个供应商、每个模型和全部参数组合都已验证。
- 音频服务和已发布 ComfyUI 工作流的真实外部联调，按用户 2026-10-16 明确的要求不纳入本轮。其已实现功能、隔离环境中的 HTTP、数据库、任务恢复及 FFmpeg 验证继续保留；以后接入真实服务时，需要单独检查该服务的协议和结果。

## 画布和运行约定

- 画布、普通页面和 Agent 共用业务命令、对象版本与权限检查。新入口必须继续使用这些约定，不能直接写入另一份业务正文，也不能重新读取新版本后覆盖用户已经提交的修改。
- 编辑时允许保存未配置完整的节点以及模型暂不支持的同类连接，界面提示具体问题；运行前仍须校验配置、输入素材、模型能力、作用域和数量预算。草稿保存成功不等于已经可以运行。
- 已提交画布计划中的专业节点及子任务自动执行。FULL_ACCESS 只适用于这些已受理任务；交互助手仍遵循用户选择的审批模式。工具白名单、对象范围、版本和数量预算继续由服务端校验。
- 执行身份、输入、模型、工作流版本和预算按运行固定。修改画布影响后续计划，历史结果继续保留；复制分支、导出和复用结果不会隐式重新提交付费生成。
- 请求已经发出但没有完整响应时，不自动重发。未知受理、取消、迟到响应、租约失效和名额释放必须保留真实状态与审计，不能把没有收到用量写成零。
- 保存结果不明时，当前打开的画布按原 requestId 确认结果，后续写入等待该请求确认。这不是持久化的离线编辑队列。
- 新增文本协议或升级 AgentScope、Google、OpenAI、Anthropic SDK 时，需要继续验证真实单次请求、工具结果消息、父子任务恢复和取消语义，避免 SDK 隐式重发。

## 媒体与交付

- 新托管媒体使用加密内容和授权网关。数据库中的密钥与存储中的密文必须一起备份；加密存储不等于可以抵御数据库密钥泄露。
- 历史 /media 地址和既有公共 URL 不会自动变为私有资源。需要凭据或特殊代理的历史来源，应接入明确的可信来源适配器，不能给任意业务 URL 附加服务端凭据。
- 使用中的存储配置不能直接换成另一个位置或删除。缺少明确的默认存储配置时应报错，不能静默切换存储后端。
- 导出节点的媒体文件和交付包只包含实际接入的内容。来源图继续保留用于追溯，查看和下载仍检查来源权限、媒体状态及交付文件版本；画布或项目导出仍按用户选择的范围收集内容。
- 删除画布节点不代表可以立即删除底层媒体。业务内容、历史版本、运行、Agent 工作空间、模板、派生文件和交付仍可能引用同一资源；清理前必须完成引用核对。
- 外置工作空间正文的引用索引未完成时，不执行相应物理清理。失败孤儿的回收遵循保留期，不能用没有活动节点替代完整引用检查。
- 已完成本地密文及数据库恢复验证；其他对象存储服务和灾备拓扑仍需按实际部署验证。
- PDF 保持文档类型，阅读器关闭 XFA 并且不执行文档脚本。PDF 输入不能隐式当成纯文本；Agent 观察结果要保留实际采样范围。部署时仍需满足 PDF.js 的 Node.js 版本要求。

## 交互和规模限制

- 顶部共享导航的动画会让读屏重复读出同一标签。用户已明确选择保持共享组件不变，这一已知问题继续保留。
- 方案内的键盘、焦点、主题、窄屏和减少动画检查已经完成，不代表完成全部辅助技术或实体触屏设备认证。
- 已完成 300/1000 节点基准和 31,000 条媒体保留历史查询验证。密集概览曾出现 233.5ms 的最长帧间隔，因此更大图和更长历史需要继续测量，不能按现有结果承诺任意规模。
- 来源批量导入会避开已有节点，但多个未结束批次同时选择同一区域时仍可能重叠，用户可以使用自动整理。
- 未配置价格时，只展示实际数量、时长和已知 Token，不估算没有依据的金额。超出已声明查询范围时直接提示，不能静默截断统计。
- 独立数据分析、完整 Skill 脚本沙箱、语音合成、口型同步、多轨专业剪辑和 3D 编辑继续按各自需求实施，不纳入这次画布完成范围。

## 版本与开发环境

- 当前产品版本为 1.3.0，本版本迁移已在发布准备中合并为七个，编号为 V1.1.3.0.0 至 V1.1.3.0.6。已发布迁移保持原样；旧开发库需要按迁移说明备份、核对结构并同步历史。
- 本轮使用独立 MySQL、Redis 和本地存储验证，没有修改用户已有数据库。旧文档里的 51055 验收库、进程号和迁移数量属于历史环境，不能作为当前运行状态。
- 旧验收环境曾在 target 下建立前端 node_modules 联接。清理构建目录前先核对实际联接和目标路径，不能把历史目录名当作当前安全范围。
- CodeGraph 索引可能尚未包含新文件。先查询索引，缺项时再读取当前代码，不能据此判断功能没有实现。
