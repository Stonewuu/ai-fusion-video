# 智能体用户配置与节点 Skill

## 用户目标

1. 系统设置中的智能体配置支持当前用户覆盖内置智能体的系统提示词、工具、默认 Skill 及相关参数。
2. 画布分镜等专业节点在选择智能体后，仍可以选择本节点使用的 Skill。
3. 完成后逐个检查配置页面与完整配置使用流程，修正交互、默认值、保存与恢复、错误反馈和可访问性问题。

## 实施约定

- 保留内置注册与工具/子 Agent 定义方式，新增按用户隔离、版本控制的覆盖配置；缺省字段继承内置值，显式空工具或 Skill 列表表示不启用。
- 可覆盖名称、系统提示词、指令模板、默认用户消息、工具开关、平台工具、已有子任务工具、MCP 选择、默认 Skill 与步数上限（0 为不限）。所有配置在服务端验证。
- 对话、画布专业节点、批量专业节点与子任务使用同一解析规则；已受理执行的系统提示词及工具清单仍使用持久化快照。节点 Skill 可沿用默认或指定本次列表，明确作用于节点及子任务。
- 运行计划与启动检查纳入用户配置和 Skill 内容指纹，配置变化必须重新预览；不得静默执行已失效 Skill 或伪造可用工具。
- 设置页以智能体、Skill、MCP、运行与存储划分清晰入口。编辑器提供搜索、多选、覆盖状态、保存反馈和恢复内置；节点侧直接选择 Skill 并说明继承关系。
- 使用真实服务与 Chrome 验证保存/刷新/恢复、用户隔离、运行快照、节点 Skill 传递和配置全流程；验收截图及审查记录归档。
