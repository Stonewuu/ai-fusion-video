## 最终范围

1. 智能体支持当前账号覆盖内置配置：名称、系统提示词、任务指令、默认任务内容、工具开关与平台工具/现有子任务/MCP 清单、默认 Skill、执行步数；0 为不限步数。
2. 工具按项目、剧本、分镜、资产、媒体生成、画布、子任务和 MCP 分类；支持跨分类搜索、分类过滤、只看已选和分组选择。工具注册、参数定义和子 Agent 定义方式保持原样。
3. 画布专业节点及批量节点支持跟随智能体默认 Skill 或单独指定；空选择明确表示不使用。根任务和子任务共享一致的配置/正文快照，刷新、恢复执行不会读取后来改变的设置。
4. 重组智能体设置入口，逐页检查七个设置页面并修复实际问题：个人资料编辑预填、配置表单未保存保护、AI 服务/模型搜索、无障碍标签、存储操作按钮可见性、节点草稿恢复及保存入口。
5. 专项修正输入框边框与焦点外圈在滚动容器边缘被裁切的问题，保留公共组件的焦点样式。完成桌面、1280×720 和 390×844 的 Chrome 验收。

## 关键实现

- 新增不可变迁移 `V1.1.3.0.36__create_agent_user_overrides.sql`，此前已核对远端最新正式 tag 为 v1.2.0；当前开发版本 1.3.0 未发布。
- 覆盖值按 userId/agentType 存储，revision 防止覆盖其他窗口的修改。缺省字段继承内置值，显式 false/0/空列表不被吞掉。
- 运行计划纳入本次智能体配置与 Skill 正文。已受理 Kernel 固定实际提示词、工具清单、父子配置及 Skill 文档；后续改设置不改变已有运行。已删除或不可用的 Skill、无效工具和父子 Skill 超限在开始前报错。
- 保存通过账号限定的本地事件和 BroadcastChannel 刷新已打开画布及助手目录，不传递配置正文或凭证。
- 节点草稿支持字符串数组及嵌套配置，用结构相等判断变更和冲突，避免刷新后误判草稿损坏或产生伪冲突。
- 分类仅为展示元数据，不扩大工具权限、画布作用域或媒体数量预算；画布自动批准策略保持生效。
