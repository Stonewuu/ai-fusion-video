## 执行中发现并修复的问题

- Responses 适配补齐 SDK 要求的 strict 参数，正确读取已完成的工具参数，拒绝非法 JSON，保留交错调用的 call_id。只按用户授权使用 Responses，没有关闭思考或替换模型。
- 模型网络、超时、限流和暂时性服务端错误最多重试 3 次，等待 2、5、10 秒；有效 Retry-After 优先。使用已保存状态，不重复提交用户输入或已完成工具；持久化失败、权限、余额、参数及工具错误不触发模型重试。
- 前端两处时间线显示重试进度，删除失败尝试的半段正文及未完成工具参数，保留已成功步骤；持久化历史与子任务回执使用同样的边界。
- 事件读取改为逐轮重新订阅，修复递归请求链随长任务增长而栈溢出的问题。摘要阶段关闭 SDK 的本地全文副本和记忆刷新，继续使用平台数据库，避免 Windows 会话文件名错误。
- 媒体绑定观察器按资源类型和 ID 处理最终变更，修复批量新增子资产时重复登记主资产封面的主键冲突。删除批量工具宣告但资源写入不支持的顶层 description 字段，描述改用元数据对应的 properties 属性。
- 未配置容量时，分段读取单页为 16,000 字，32,000 字以内直接返回；配置容量时仍按预算限制，单页最多 64,000 字。查询分镜总览只返回集场目录，详情最多读取一集。
- 分集编写器原先只能接收分集 ID，父任务无法传递具体复核要求。现有调用增加 task，同时保留结构化 ID；继续时带上已完成范围及待查事项，不新增工具。对已有分镜的完整复核默认按场次派发，父任务维护完成清单，避免整集反复读取和同值保存。
