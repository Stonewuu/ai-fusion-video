# 智能体提示词与场景关联

范围：检查 19 个内置智能体及主流程覆盖提示词，核对工具、输入、版本、资产准备、影视连续性和结果反馈。每个镜头在现有创建或修改流程中直接关联有效场景，不新增专用绑定工具。

按用户最新要求不修补旧镜头。代码与测试完成后，备份《谁让他修仙的》现有全部分镜，通过现有版本化清空接口删除，再由平台剧本转分镜智能体依据已解析的 24 集、176 个有效场次重新生成。原 180 条场次记录包含 4 条已删除历史记录，不纳入本次范围。使用用户配置的 pro/gpt-6.1-terra，只按用户追加授权调整请求模式，不由外部脚本编写镜头或手工绑定资产。

验证分为资源事务与参考图输入测试、Chrome 前端检查、平台智能体重建及持久化结果核对。检查集场覆盖、顺序、每镜场景有效性与人物道具对应关系；关联存在不代替图片目视验收。

模型暂时性失败自动重试必须保留原来的子任务、会话和已完成的工具结果；重试有次数与间隔限制，取消立即生效，状态保存失败不继续。对话与运行通知同步显示重试，持久化历史不混入失败响应的半段内容。
