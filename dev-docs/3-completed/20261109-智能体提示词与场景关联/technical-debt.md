# 实现边界与后续验证

每个镜头关联一个实际场景；跨地点段落拆为可拍摄的镜头。历史漏绑记录不自动填入猜测的场景，本项目按用户要求重建；其他项目的历史漏绑镜头再次保存时需要选择有效场景。

本轮没有重新生成首尾帧或视频，不能把引用正确推断为影视画面已经通过视觉验收。部分新增场景、人物造型仍没有图片，生成首尾帧前应由平台资产生图流程补齐。现有生成工具会检查必需参考图，不以另一地点或文字替代缺图。

部分分镜包含长对白或旁白，例如第 23 集 23-4 有一镜为 52 秒。后续视频制作需结合配音节奏和选用模型的时长能力检查是否拆镜或分段；此次未用视频生成验证这些镜头。第 23 集送虫后的去向在已解析剧本中未交代，复核未补造情节。

自动重试针对正在执行的模型请求，不自动重启已结束的旧子任务，也不替代服务重启恢复。连续重试 3 次仍失败时报告失败，保留持久化的上下文与业务数据。供应商要求等待超过 2 分钟时不提前重发。接口重试可能产生多次模型计费，每次请求独立记录；业务工具不会因此重放。

会话仍受模型容量与摘要策略约束，保留上下文不表示把全部历史原文无限累加入每次请求。完整事件和状态保存在平台数据库；长内容复核通过现有工具的 task 传递明确范围，按场次完成并交付结果。此次未修改用户选择的模型容量、渠道、密钥或思考配置。
