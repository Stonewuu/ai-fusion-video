# 后端交付

## 清空

新增 `POST /api/script/{id}/clearContent`，请求携带当前 version 和 requestId。返回同一个剧本容器，分集、场次、原文、梗概及解析状态清空；项目名称、分镜和资产保留。已有分镜关联变为待重新关联，不自动选择同名或同集号的新剧本。

清空分镜继续使用既有集合清空接口，移除分集、场次和镜头，清除描述并重置状态和总时长；固定分镜容器、列配置、剧本及资产保留。

两类清空均沿用资源命令的当前用户权限、乐观版本、事务、幂等回执、变更事件和审计。旧版本请求不会覆盖更新后的数据。

## 解析与关联

重新解析本集仅替换场次并保留分集 ID。整份原文替换或清空会使旧关联返回 `scriptBindingStatus=missing`；Agent 目录不再暴露失效的 scriptEpisodeId。显式关联新剧本集仅更新关联，保留原镜头。

重新生成分镜不再需要先清空：先读取剧本、准备首场，保存首场时一次替换旧场次。首场参数或关联校验失败时事务回滚，旧镜头保留。

完整解析默认覆盖全部待解析范围。子任务接收 replaceExisting 与 task，分别传递重解析授权和续跑进度；首批替换成功后继续追加，逐批完成所有授权分集。范围和覆盖指令通过任务消息传递，保留现有只传 scriptId 的调用方式。

## 验证范围

隔离 MySQL 和 Redis 的回归覆盖清空后统计、容器和资产保留、失效关联、重新关联、首场替换回滚、旧版本拒绝、权限拒绝及幂等重放。已通过 87 项后端回归及清空 HTTP 路由单类 5 项复核（其中新增 1 项），无跳过。未调用外部模型执行几百集解析；前端与页面验证由主任务记录。

## 概览与批量解析入口

项目概览和剧本页共用“AI 解析”入口，主按钮直接处理全部待解析分集，无需逐集勾选。独立范围设置支持起止集号、包含已完成项与重新解析全部；已有场次覆盖需要确认。非法范围立即指出错误字段，按钮禁用。默认任务不枚举几百个 ID，按范围处理时才传确切分集 ID。

Chrome 实测 1505 集时默认选中 1502 个未完成分集；100 至 600 集范围选中 501 集；全部重解析显示 1505 集及已有场次覆盖确认。检查了首尾字段焦点、错误边框、禁用状态及明暗主题。

概览提供清空剧本、清空分镜入口及影响范围确认，取消保持原内容。使用本任务创建的本地项目调用清空接口并核对页面：剧本清空后分镜 1 集、1 场、1 镜保留；页面提示重新关联，选中新剧本集后原镜头仍在；分镜清空后统计归零，剧本与项目资产保留。未清空用户项目。

本地后端已重新启动加载新接口，前端生产构建、TypeScript、ESLint 及范围选择测试通过。没有调用外部模型执行数百集任务；批量调度的提示词、参数及范围逻辑已检查。
