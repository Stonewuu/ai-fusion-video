# v1.4.1 发布结果

融光 v1.4.1 于北京时间 2026 年 11 月 24 日 01:20 正式发布，已设为 GitHub 最新版本。版本标签指向 `v-1.4.1` 分支的 `e6092501cd0ad32dd7a4d67940a047914813d5fd`。[GitHub Release](https://github.com/Stonewuu/ai-fusion-video/releases/tag/v1.4.1)

## 发布范围

本版包含画布图片、视频和文本快捷生成，文本 AI 写作与结果写回，节点悬浮面板和侧边抽屉，模型厂商图标与搜索，参考素材断开及输入端口添加前置节点，以及分镜合成长音轨停顿修复。工作区中的源码、测试、项目配置和交付文档已统一提交，前后端版本均为 `1.4.1`。

## 验证

- 前端 290 项脚本测试、TypeScript 检查和生产构建通过。ESLint 为 0 个错误、6 条已有警告。
- 后端 1,207 项常规测试通过，已启用 FFmpeg 用例，无失败或跳过。后端 JAR 打包通过。
- 55 项画布运行与 19 项媒体合成集成测试通过，使用临时 MySQL、Redis、MinIO 和本地模拟供应商接口，覆盖生成输入预览、权限、版本冲突、镜头切换、任务状态和结果写回。
- 应用启动完成 Flyway 校验；本版没有新增或修改数据库迁移。
