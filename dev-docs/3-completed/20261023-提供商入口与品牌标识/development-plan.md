# 提供商入口与品牌标识调整

日期：2026-10-23。状态：实现及页面验收完成。

## 最终流程

1. 添加 API 配置直接打开现有表单，不再先出现赞助商选择页。
2. 常用提供商中的赞助商显示品牌、赞助标签和获取密钥链接；点击配置进入指定平台快速配置。普通提供商继续自动填入地址及协议。
3. 快速配置只填写密钥并选择模型；手动配置与快速配置之间传递已有表单值。
4. 已配置赞助商点击获取模型或添加模型后自动读取；失败才显示重试，不再要求重复点击读取。

## 组织与验证

平台条目、连接字段、模型选择和读取 Hook 分离；共用现有发现、幂等保存和模型追加接口。删除无入口的旧选择组件，不增加后端 API 或迁移。官方平台 Logo 作为静态品牌资源，模型及普通平台图标复用现有图标库。

验证新建、快速/手动往返、已有账号自动读取、失败重试、普通地址预填、Logo、明暗和窄屏焦点/滚动。只用本地模拟上游，不调用真实赞助商密钥。
