# 完成说明

2026-10-30 已完成代码修改，尚未运行检查或测试。

## 最终行为

画布可以缩小到 1%。“查看全部”“适应画布”、保存视图恢复和版本快照预览使用同一组缩放限制。

选中节点后，分别向前寻找全部祖先、向后寻找全部后代，标亮遍历经过的节点和连线。遍历过程中不改变方向，因此不会从共同父节点扩展到兄弟分支，也不会从下游汇合点扩展到其他输入分支。多选时合并各个选中节点的链路。

关联节点保留类型颜色并增强边框与标题背景，关联连线加粗，其他分支降低透明度。取消选择后恢复正常显示。高亮不修改节点和连线的选中状态，不扩大拖动、删除或运行范围，也不改变连线的数据、告警颜色或层级。

## 关键实现

- `lib/canvas/viewport-limits.ts` 集中定义缩放范围，编辑器、视图保存恢复及版本预览共同使用。
- `lib/canvas/selection-chain.ts` 建立输入和输出索引，通过独立的迭代遍历计算链路。
- `components/canvas/editor/use-chain-highlight.ts` 仅给画布显示数据增加高亮样式，复用原有节点数据和交互状态。
- `scripts/canvas-editor.test.mjs` 新增回归用例，保护不扩展兄弟分支、汇合输入、多选及一万节点深链路的行为。
