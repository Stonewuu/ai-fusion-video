# 文本、图片和视频真实生成验收完成记录

2026-10-25 按用户最新确定的范围完成真实文本、图片和视频生成测试。Sonilo 和 ComfyUI 不在本轮范围内。

| 类型 | 渠道与模型 | 请求规模 | 实际结果 |
| --- | --- | --- | --- |
| 文本 | 无限星河 gpt-4o-mini | 只要求回复 OK，输出上限 16 Token | 返回 OK，约 2.4 秒完成 |
| 图片 | 无限星河 gpt-image-2 | 一张 1K 正方形图片 | 1024×1024 PNG，1,380,306 字节 |
| 视频 | 秘塔 MiniMax-H3 | 一段 4 秒、480p 视频，关闭额外提示词优化和优先通道 | 832×480、4.458 秒 MP4，2,810,994 字节 |

图片与视频都通过项目正式生成接口提交，并经过实际供应商请求、任务终态、托管媒体接收和授权下载。下载文件的 SHA-256 与媒体记录一致，FFmpeg 完整解码通过，图片和视频采样画面也已实际查看。

首次图片测试优先选择报价更低的 gpt-image-2.5-sunburst，但供应商返回 HTTP 503“没有可用渠道”。项目正确保存失败原因，没有生成虚假产物，也没有自动重试。确认该请求已经明确失败后，另行选择 gpt-image-2 并提交一次新请求，保留原失败记录。

本轮共四次生成请求，其中三次成功、一次因渠道不可用失败。三个媒体任务的提交尝试各为一次，全部到达终态且并发名额归零。没有重复生成已经成功的文本或视频。实际扣费以供应商账单为准，本轮未测量账户扣款差额。

验收使用独立 MySQL、Redis、后端和本地存储。结束后两个提供商配置均已禁用并清除密钥，四个测试模型均已禁用，临时服务和容器已清理，生成产物保留在本地验收目录中。没有修改用户原有项目配置、业务代码或数据库迁移。
