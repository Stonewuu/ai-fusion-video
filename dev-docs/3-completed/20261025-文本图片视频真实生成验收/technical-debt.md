# 验证范围与维护事项

- 模型出现在密钥的可用列表中，表示账号允许调用该模型，不保证供应商此刻一定有可用渠道。gpt-image-2.5-sunburst 的 503 应保留为该渠道当时的结果，不能改成成功，也不因此在业务代码中自动切换模型。
- 实际扣费以供应商账单为准。本轮通过限制输出长度、图片数量、视频时长、分辨率及关闭额外选项来控制消耗，不把公开报价当成已经核对的扣款金额。
- 实际生成文件的时长和尺寸需要从文件中读取，不能直接用请求参数填写结果。例如本轮视频请求为 4 秒，实际文件为 4.458 秒。
- 密钥只从用户指定文件读取；临时数据库中的配置在所有请求结束后清除密钥。验收附件保留在被 Git 忽略的 .local 目录中。
