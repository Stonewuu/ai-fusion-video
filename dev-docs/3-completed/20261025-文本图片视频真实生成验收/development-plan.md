# 文本、图片和视频真实生成验收

用户本轮确认只测试真实文本、图片和视频生成。Sonilo 配乐、音效和 ComfyUI 不在本轮范围内。

使用用户指定本地文件中的真实密钥，通过项目的提供商配置、文本检测和图片／视频生成接口发起请求。数据库、Redis 和媒体存储放在独立验收环境中，避免改变原有项目配置。

文本使用 gpt-4o-mini，只要求回复 OK，最多输出 16 个 Token。图片只生成一张 1K 正方形图片，优先核对渠道报价。视频使用 MiniMax-H3 的 4 秒、480p 标准通道，关闭额外提示词优化和优先通道。

提交前保存稳定请求标识；提交后只查询原任务。明确失败时先检查原因，保留失败记录，不能把反复提交当作轮询。成功后检查任务终态、托管媒体状态、授权下载、内容摘要和完整解码，并实际查看产物。

完成后清除临时配置里的密钥，保留脱敏结果和本地测试产物，更新完成记录。验证结果只覆盖实际使用的渠道和模型，不推断其他模型当前也有可用渠道。
