# 分集预览删除

在“检查分集”中增加删除本集和撤销删除，供用户移除前言、广告、分隔页等不需要导入的内容。删除后更新分集编号和总字数，导入只保存保留内容。

预览单独维护可编辑的原文副本，删除时同时移除文字并重排分界。返回原文后仍可重新识别上传的完整内容。保留后端连续分界校验，不允许通过分界空缺隐式丢弃原文。

验证删除首集、中间集、末集、全部删除、撤销、删除后合并及实际导入，检查桌面、窄屏、明暗主题和键盘焦点。

根据补充需求，将目录和详情入口统一放入工作区顶部工具栏。大屏控制左右侧栏收起、展开并记住选择；窄屏通过相同位置的入口打开抽屉，移除原来独立占一行的导航。收起后保留当前场次和滚动位置，编辑区获得更多宽度。

左右侧栏保留同一 DOM 容器，用 200 毫秒栏宽过渡、内容淡入淡出和短距离位移表达切换；内部内容保持固定宽度，避免收起时挤压文字。减少动态效果模式下关闭过渡。目录改为跟随父容器宽度，抽屉标题、刷新、关闭按钮同排，列表使用覆盖式滚动条。
