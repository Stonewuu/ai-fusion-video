# 分集预览删除与侧栏交互

## 最终范围

- “检查分集”增加删除本集和撤销删除，数量、字数、选中位置和编号同步更新。删空后显示空状态并禁用导入。
- 删除同时移除本次导入副本中的文字并重排分界。合并不会带回已删除的文字；返回原文仍可重新识别完整上传内容。后端连续分界校验保持原样。
- 目录与详情入口统一放在顶部工具栏：桌面控制侧栏，小屏打开抽屉。删除原有独立导航行和重复的侧栏开关。
- 左右侧栏使用 200 毫秒宽度过渡及内容淡入淡出、位移，内部保持固定宽度；收起状态通过浏览器本地存储记忆，保留选中对象与列表滚动状态，并支持减少动态效果设置。
- 修复小屏目录沿用桌面固定宽度造成的空白；列表改用覆盖式滚动条，抽屉标题、刷新、关闭按钮在同一行，关闭按钮和其他工具栏控件统一为 36 像素。

## 验证结果

- 原文导入 Node 测试 7 项通过，新增用例保护首集、中间集、末集及唯一分集删除、删除后合并、原预览不可变性、换行与完整字符。
- TypeScript、修改文件 ESLint、生产构建和 Git 差异空白检查通过。
- Chrome 验证删除、撤销、删空、删除后合并、返回原文、字段错误提示和键盘操作，修复撤销后焦点返回弹窗容器、窄屏删除后按钮滑出可见区的问题。
- 本地验收项目通过 HTTP 接口追加保留的两集；数据库核对两条原文与预期一致，均不含被删除的前言和广告，集号连续。未调用模型或视频供应商接口。
- Chrome 检查 390、1200、1400、1600 像素及默认桌面宽度、明暗主题。390 像素下抽屉宽 358、内容宽 357；1200 像素下抽屉宽 384、内容宽 383，除边框外无多余空白和横向溢出。
- 桌面侧栏最终宽度分别为 256 和 288 像素，收起为 0；浏览器计算样式确认宽度过渡为 0.2 秒。两个侧栏刷新后恢复收起状态，窄屏抽屉不受桌面收起状态影响，跨断点时不会重复显示。

## 交付状态

分集预览删除已随 v1.4.0 发布。撤销保留最近一次删除记录，继续编辑标题或分界后清除该记录，避免覆盖后续编辑。
