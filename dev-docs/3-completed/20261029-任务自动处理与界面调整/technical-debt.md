# 技术债务与边界

- 未新增数据库迁移、兼容协议或后台守护进程。历史待核实记录由现有任务调度自动处理，已发布的数据库迁移和审计记录保持不变。
- 远端结果未知不表示供应商已经停止，也不代表未产生费用；系统只结束本地等待，不自动重发请求，不把未知用量当成已确认的零用量。
- 迟到回执和响应可追加到原记录，不能重新占用名额、重启已结束任务或覆盖业务内容。权限失效后的自动处理只观察原调用并清理执行状态。
- 已收到成功结果后的“重新保存结果”操作保留，不触发供应商重新生成。普通批量失败的重试、使用成功项等业务选择仍保留；包含远端结果未知的批次直接自动结束。
- 本地后端未重启。界面验收中的异常详情使用模拟数据；生产环境和付费供应商链路未执行验证。
