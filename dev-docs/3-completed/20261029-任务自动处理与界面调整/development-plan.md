# 任务自动处理与界面调整

## 范围

1. 将图片、视频、画布文本、音频、ComfyUI 和 MCP 的异常收尾统一改为自动处理。已受理且可查询的任务继续自动查询或取消；无法确认的保留远端结果未知，结束本地等待并回收资源，不自动重新提交。
2. 移除“执行核实”菜单和人工确认入口，将异常记录接入“运行与通知”的任务详情，保留权限校验及历史记录。
3. 移除工具页“正在确认账号与团队…”加载横条，检查其他页面同类冗余提示。用户已明确本次截图指向该横条，不据此调整路由切换逻辑。
4. 为画布左侧项目/素材栏和右侧编辑/运行栏添加开合动画，兼顾窄屏、焦点可见性和减少动态效果设置。

## 验证

后端使用隔离数据库和本地模型/工具服务验证状态查询、取消、超时、断流、权限失效、历史占用回收和禁止重发。前端执行相关回归、类型及 Lint 检查，通过 Chrome 验证任务详情、加载状态和侧栏开合。
