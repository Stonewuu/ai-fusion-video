# 完成说明

任务中断和遗留执行不再依赖人工核实。图片/视频、画布文本、MCP、音频、ComfyUI、分集合成及智能体模型调用使用现有调度自动查询或结束本地等待；无法确认的保留“远端结果未知”并释放本地名额。迟到响应只保留在原记录，未知请求不自动重发。包含未知子项的批次会自动停止后续执行。

“执行核实”菜单、独立页面和人工确认接口已删除。异常与中断记录接入“运行与通知”的列表及详情，展示本地结束状态、并发占用、原调用回执和历史处理记录。查询按发起用户隔离，权限失效不允许继续发布业务结果。

工具页不再显示“正在确认账号与团队…”加载横条。画布左右侧栏增加展开 200ms、收起 150ms 的滑动和透明度过渡；内容在关闭后保留，焦点回到入口，窄屏覆盖区域不再接收交互，减少动态效果设置可关闭过渡。全局菜单切换保留共享布局的修改也已保留。

验证覆盖：前端 87 项回归、TypeScript、修改文件 ESLint；图片生成 18 项、ComfyUI 12 项、音频与分集合成 17 项集成测试，画布整组 54 项中发现的未知批次等待问题已修复，并在最终 40 项集成回归中验证通过；另外 42 项后端单元测试通过。集成测试使用隔离 MySQL/Redis 与本地供应商服务，验证回执丢失、持续查询、等待期限、撤权、迟到结果、历史占用回收、权限隔离及禁止重发。测试还发现 MCP 模板预览遗漏固定参数校验，已复用运行计划校验修复并通过原用例。

Chrome 验证覆盖工具加载、左右侧栏开合、搜索内容保留、焦点与窄屏布局，以及异常记录详情。详情界面使用模拟异常记录，临时验收路由已移除。未新增或修改数据库迁移，尚未发布；当前本地后端重启后新流程生效。
