# 当前进度

## 已完成

- 分支为 v-1.3.1，最终范围限定为文字生成、图像生成、视频生成、音频生成。已删除“模型工具”页面、菜单、专用前端组件和通用任务接口，删除转写、嵌入、实时会话、实时翻译、研究的执行代码、预设与测试。音乐流只用于生成音频文件，不提供实时会话入口。
- 模型配置、Google 自动获取、Models.dev 和内置预设统一限定四类。音乐并入音频生成；音频在设置页提供“试听”入口，输入朗读内容或音乐描述后生成、保存并播放。
- 预设统一为单一入口，包含内置与联网搜索、关键词与厂商筛选、参数预览、应用和覆盖提示。保留用户已有名称和调用标识；Flow 等特殊渠道保留自己的预设。
- Omni/Veo 复用原有视频任务与媒体保存流程。音频使用独立任务，保留权限、幂等、并发、租约和保存重试。供应商响应先落库再解析；没有音频的响应结束为“未生成音频”，不显示保存重试，也不自动重发生成请求。
- 用户批准的 Interactions 角色已创建并授予现有服务账号，只包含 aiplatform.interactions.create 与 aiplatform.interactions.get，原有角色保留。
- 本地已应用 1.1.3.1.2，任务表收敛为音频生成表，音乐配置从旧类型转为音频，其他新增类型停用。迁移前已备份；原有音频和视频保留，媒体引用查询已同步。

## 验证结果

- 相关 Java 测试共 50 项通过。隔离 MySQL 验证迁移、并发额度、过期工作者隔离、用户/团队权限、接收结果恢复与保存重试；空音频响应不会被标为完成或触发再次生成。
- 前端 14 项表单、协议和预设回归通过；相关组件 ESLint、TypeScript 与生产构建通过。构建产物不含旧通用任务类、旧预设文件或模型工具路由。
- Chrome 验证四类选择、音频预设应用后正确选择 Vertex 协议、菜单清理、试听表单及历史播放。检查了桌面、420px 窄屏、明暗主题、首末字段焦点、空输入校验与恢复；焦点外圈有 8px 水平安全距离，无横向溢出。
- Google 目录实际返回 26 个生成型号：文字 15、图片 5、视频 2、音频 4；含 Omni 1.1 Preview 和 1.2，无已移除类型。目录未返回的官方型号通过预设配置，不伪造账号目录结果。
- Omni 1.2 已在平台生成并自动保存视频，Chrome 播放确认 640×360、约 3.03 秒。Gemini 3.8 Flash TTS 的 4.88 秒语音与 Lyria 002 的 32.77 秒音乐在迁移后仍可播放，媒体状态均为 READY，引用检查正确识别任务历史。
- 本地后端与前端已启动，Flyway 校验 37 条迁移通过，默认文本、生图和视频模型保持原配置。
