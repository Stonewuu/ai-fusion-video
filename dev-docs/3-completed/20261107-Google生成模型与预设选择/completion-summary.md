# Google 生成模型与预设选择完成记录

## 最终范围

模型统一为文字、图像、视频、音频生成四类。“模型工具”菜单、页面与通用接口已删除，转写、嵌入、实时会话、翻译和研究相关代码、预设及测试同步删除。语音合成和音乐归入音频生成，在模型设置中提供试听。

预设改成一个选择入口，内置和 Models.dev 联网搜索共同支持筛选、预览与应用。Google 官方与特殊渠道分别匹配自己的预设，普通渠道不显示赞助商专用协议。

## 实现与数据

Omni、Veo 采用对应原生接口并复用平台视频任务。音频任务先保存供应商响应，再解析并写入媒体库；保留幂等、权限、并发限制和执行租约。未生成音频与文件保存失败分开处理，避免无效保存重试和重复生成。

用户批准的两项 Interactions 权限已通过自定义角色授予服务账号。数据库已备份并迁移到 1.1.3.1.2，音乐配置转为音频类型，历史素材和媒体引用保留。旧代码和资源也已从运行包中清除。
