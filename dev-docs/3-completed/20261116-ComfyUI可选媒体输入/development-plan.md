# ComfyUI 可选媒体输入

Issue #74 反映 H3 工作流预接多个媒体加载节点后，平台要求填满全部绑定位置。核对发现输入绑定没有可选标记，能力计算和提交校验均把最高绑定索引作为必须提供的数量。视频与音频上传绑定还会被直接拒绝。

增加可选媒体绑定，分别计算最多数量和提供时所需的最少数量。未提供的可选媒体断开对应连接并移除不再使用的加载分支，工作流已配置输出与共享依赖继续保留。在线校验确认下游输入允许省略。音视频复用 ComfyUI 通用上传接口。

前端绑定编辑器增加可选开关，试运行支持三种媒体并省略空输入。Agent、API、画布使用同一能力描述。验证部分输入、零输入、必需输入、共享节点、媒体上传、旧版本与配置序列化。
