# Issue 74 修复结果

已确认问题存在。原实现以最高绑定索引计算 minimumWhenProvided，并在提交时要求所有对应索引都有值；没有可选标记，因而九个绑定位置会要求填满。音频和视频上传类型还会被独立拒绝。

## 功能

媒体输入绑定新增“可选”。最多数量由全部绑定位置决定，提供时所需最少数量由非可选位置决定，Agent、API 与画布共用该能力描述。未提供可选输入时，执行副本断开相应连接，移除对应加载节点与由此产生的孤立依赖；保留共享节点、已配置输出及其他绑定。工作流版本原文不变。

在线校验使用目标实例的节点定义核对下游输入确实可省略。缺省后不再使用的加载节点不要求示例文件存在；模型文件等其他选项继续校验。同一素材的多个绑定按组模拟缺省。

音视频通过 ComfyUI 通用文件上传接口提交，保留媒体类型、扩展名和服务端文件描述；采用临时文件流式传输并清理。试运行继续校验媒体权限、类型和冻结版本。前端支持图片、音频、视频上传与可选输入留空。

## 使用

已有工作流在新版本的输入绑定中勾选需要按需提供的媒体位置为“可选”，完成校验和试运行后发布。旧版本未设置 optional 的绑定保留原行为。若连接到了下游节点的必填输入，在线校验会指出需要调整的位置。
