# 维护边界

未增加兼容分支或 fallback，未将布局计算转移到服务器或页面主线程。应用 Worker 动态加载 ELK API，由独立 ELK Worker 处理算法消息，避免第三方入口覆盖应用的消息处理函数。

线程回归使用 Node 独立线程提供 Worker 消息接口和 `self` 环境，执行应用入口及 ELK 脚本，覆盖此前遗漏的运行环境分支。该测试不替代浏览器打包与页面验收，本次另在 Chrome 中完成验证。

当前浏览器验证覆盖 13 节点项目关系画布；100 节点、400 连线的复杂图使用离线回归，最终一次约 754 毫秒。两项耗时范围不同，不据此推断所有画布或设备的性能。原有锁定、选区、分组约束和 15 秒计算上限保持。

加载方式依据 [ELK 浏览器用法](https://github.com/kieler/elkjs#browser)。
