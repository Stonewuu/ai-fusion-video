# 子任务并发控制

所有平台子 Agent 统一经过受理入口。同一父任务的活动子任务合计最多 5 个，超出请求等待名额，已有工具调用重放继续使用原任务。

受理使用父任务数据库锁保证并发计数与新建原子完成；等待在事务外进行。父任务取消、期限或所有权失效时停止等待。完成、失败、取消进入终态后释放名额，等待确认与外部结果的任务仍占位。

公共执行约定提示所有流程每批最多 5 个子 Agent；资产生图的旧 10 个任务提示同步改为 5。剧本解析、故事转剧本、剧本转分镜、资产生图、分镜首尾帧及视频生成均经过相同执行入口。

回归保护并发计数、不同子类型共用名额、幂等重放、等待后启动、父任务取消与租约失效，以及所有内置子工具的统一注册通路。
