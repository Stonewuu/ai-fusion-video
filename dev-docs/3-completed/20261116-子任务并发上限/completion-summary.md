# 子任务并发上限交付

每个父任务的所有子工具共用 5 个活动名额，达到上限的调用等待其他子任务结束。该规则覆盖剧本解析、故事转剧本、剧本转分镜、资产生图、分镜首尾帧、视频生成及自定义平台子 Agent。

所有子工具统一经 AgentScopeSubAgentToolAdapter、PlatformSubAgentRunService 和 AgentRunCoordinator.startChild 受理。父任务行锁保护计数与创建；COUNT 查询只读取活动数量。重复工具调用先恢复已存在任务，不重复创建或占位。等待在数据库事务外进行，父任务取消、过期或租约失效后停止。完成、失败或取消进入终态后释放名额，等待确认或外部结果时仍占位。

公共执行约定要求所有子工具合计最多并行 5 个，业务要求更小批次时按其要求执行。资产生图原有每轮 10 个独立任务同步改为 5。一次批量解析仍只创建一个 pipeline，内部子任务共用用户会话并保留各自上下文。

隔离 MySQL 回归已通过：AgentRunStartIT 与 PlatformSubAgentRunServiceIT 共 12 项；COUNT 优化后 3 项行为复核；全流程复核 8 项覆盖混合六种子 Agent 同时申请仅五个受理，以及所有内置子工具使用同一适配器。已有过期时间测试用数据库时间构造输入，拒绝过期请求的断言保持不变。

本地后端已重新启动加载公共调度提示。并发上限按父任务计算，各独立 pipeline 的名额分别管理。
