# 完成摘要

## 数据库访问

完成最初 108 个生产文件涉及的直接 JDBC 访问迁移。生产源码中不再使用 JdbcTemplate、NamedParameterJdbcTemplate、SimpleJdbcInsert、手工连接或自定义 JDBC 字符串类型处理器；SQL 注解及业务层 SQL 拼接也已清除。

单表操作使用 MyBatis-Plus BaseMapper、Lambda 条件和内置原子递增/分页；行锁、跨表查询、数据库时钟、不可分割状态更新及复合主键命令放入 Mapper XML。保留账号/团队过滤、逻辑删除、版本冲突、幂等受理、事务发件箱、不可变回执与失败状态。

媒体写入与物理清理共用可续租的 Redis 对象锁，忙碌文件立即延后；数据库事务仅覆盖状态、权限及清理资格校验，文件加密、上传和删除不占用数据库连接。没有连接级命名锁残留或手工连接释放代码。测试上下文统一加载实际 Mapper XML，数据库测试继续使用隔离容器。

## 规则与资料整理

项目规则已补充控制语句强制大括号、多行代码块、真实边界校验、按业务风险选择测试、禁止虚构兼容与无效 fallback，以及 MyBatis-Plus/XML 访问约定。整理了无独立验证价值的配置自比和常量检查，保留关键协议、权限、计算及状态测试。

旧开发文档中的 502 个验收附件及两份走查附件已移入仓库内的 Git 忽略目录，清理原始证据索引和失效附件依赖。dev-docs 只保留可独立阅读的 Markdown 计划、进度、边界与完成摘要。

## 2026-10-21 迁移复查

对照迁移前源码检查事务、锁、权限与幂等，修正默认一级缓存复用事务内旧权限/租约结果的问题：生产和隔离集成上下文统一使用 STATEMENT 范围。媒体互斥外层事务显式采用 READ_COMMITTED，避免覆盖内部清理方法的隔离级别。项目拥有者成员创建/删除继续使用数据库 CURRENT_TIMESTAMP，分镜创建使用 Instant 保留原绝对时间绑定。

移除 22 条普通手写 SQL，改用 BaseMapper 条件查询、删除和原子更新；复合主键表不伪造单字段主键。删除无独立职责的状态检查包装及重复集合转换，存在性检查不再加载整行任务快照。锁、数据库时钟、联合查询、历史删除数据读取与原子竞争仍保留明确的 Mapper XML。

未新增测试类：在现有用例中补充时间与实际事务隔离断言，增加同事务观察独立事务撤权的回归；终态通知检查改为从独立事务读取已提交状态。修正两组旧测试的 Spring 上下文生命周期，消除后台工作者访问已销毁测试库的干扰。最终 20 组、294 项关键集成测试无失败、错误或跳过，IDE 编译、格式检查与后端打包通过。未改动 Flyway 脚本。

当时媒体互斥由连接级命名锁改为事务行锁；2026-10-22 进一步发现该实现会在文件 I/O 期间持有长事务，现已替换，不能沿用本次复查的行锁结论作为当前实现说明。

复查后的构建已更新到本地验收后端 18092，前端 3023 保持可用；启动再次通过 64 条 Flyway 校验，数据库仍为专用验收库。

## 2026-10-22 媒体 I/O 与事务分离

确认原行锁回调覆盖整个加密、磁盘写入、S3 上传与删除，确实会在慢 I/O 期间占用事务和连接。现改用 Spring Integration RedisLockRegistry，复用已有 Redis，以对象标识和媒体/交付域区分锁；独立线程自动续租，忙碌时立即延后清理，锁失效则操作失败。状态读取使用 BaseMapper，清理资格与结果登记继续使用原有短事务。

上传、来源导入、预览和存储入口直接拒绝外层实际事务及同步作用域，避免用 NEVER 创建空同步作用域后仍绑定查询连接，也避免 NOT_SUPPORTED 暂停事务却继续占用其连接。加密与存储期间不持有数据库连接；S3 请求总超时为写入十分钟、删除三十秒。权限、来源版本、独立对象键、上传代数、任务和清理租约校验保持。

9 组、95 项隔离集成测试全部通过，无失败、错误或跳过；其中 13 项生命周期用例包含慢加密、慢 S3 上传/删除、独立锁注册表的跨实例互斥、旧代数禁止发布、锁丢失不得解除新持有者的锁，以及实际事务/空同步作用域误用。暂停 I/O 时断言无数据库事务及连接绑定，并要求另一线程在限时内完成状态更新、过期处理及其他文件上传。Maven 编译、打包和修改文件的控制块格式检查通过；IDE 的 MapStruct 生成源重复问题单独记录，不计为成功验证。

项目规则已加入耗时 I/O 与数据库事务分离约束。本次未新增或修改迁移脚本，没有新增 JDBC、无锁 fallback 或自制 Redis Lua 锁协议。多实例部署必须统一切换锁实现，不混跑旧行锁工作者与新对象锁工作者；Redis 租约不替代数据库执行隔离，也不宣称数据库与对象存储原子提交。

修复构建已更新到本地验收后端 18092，先停止旧进程再启动新进程，避免锁域混用；启动通过 64 条 Flyway validate，继续使用专用 MySQL 51055 与 Redis 51057，前端 3023 保持运行。
