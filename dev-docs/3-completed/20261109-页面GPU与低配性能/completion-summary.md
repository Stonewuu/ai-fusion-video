# 页面 GPU 与低配性能优化

已在 v-1.3.1 完成修复、构建和本地验证，尚未发布。

后续用户要求保留特色动效，助手静态状态环和认证静态背景已由“20261109-保留动效与滚动修复”替换为优化后的动画。下面的静态方案与采样是当时的验证记录，不代表当前最终实现；素材占位图和助手首次点击修复继续保留。

## 结果

| 相同条件下的空闲采样 | 优化前 | 优化后 |
| --- | --- | --- |
| 分镜页 | 68%–72% | 0% |
| 认证布局组件预览 | 70%–74% | 0% |

每组均为本机 Chrome GPU 进程的 8 次 Windows 性能计数器采样，认证布局和分镜页分别在同一视口对比。数据表示空闲状态的观察结果，不表示动态操作不再使用 GPU。

## 修改

素材占位图移除持续流光和模糊脉冲，助手入口改用静态状态环，分镜绑定提醒保留状态文字并去掉循环光圈。删除无用装饰 DOM、光晕配置和关键帧，避免大量空素材也持续渲染。

登录、注册、初始化和找回密码切换到业务共享的静态认证布局，停止全屏 WebGL 绘制，保留短过渡、成功跳转、减少动态效果及长表单滚动。共享 UI 组件源码未修改。

助手展开后的透明交互保护层只在窗口转换期间存在，转换结束自动解除，修复低速 CPU 检查中首次点击被吞掉的问题。

## 验证与交付

Chrome 已检查项目分镜、资产、仪表盘、助手鼠标及键盘操作、主题切换；4 倍 CPU 限速下资产筛选和助手首次收起可用。认证组件预览检查成功回调、窄屏长表单、焦点、校验及禁用状态。TypeScript、针对修改组件的 ESLint、生产构建和差异格式检查通过。

本地修改已生效，原有前后端保持运行；临时预览已停止，所有测试限速和视口设置已恢复。没有修改模型、业务数据、认证凭据或浏览器硬件加速设置。
