# 当前进度

后续状态：助手波纹和认证背景已按用户要求恢复动画，最终实现与新一轮测量见“20261109-保留动效与滚动修复”。以下内容保留为上一轮交付记录。

已在 v-1.3.1 完成并在本地生效。分镜页、资产页和仪表盘静止时不再持续播放装饰动画；认证页面业务入口改为静态背景，共享 components/ui 源码保持不变。

## 原因与修改

分镜页有 254 个素材占位图，每个同时播放流光和模糊脉冲。空素材、图片失效并不处于加载状态，现改为静态类型图标和渐变背景，失效提示仍保留。删除对应无用 DOM、光晕配置和 shimmer 关键帧。

助手空闲入口的三层循环波纹改为单层静态状态环，运行及完成状态仍使用颜色区分。未绑定剧本集的提醒去掉循环光圈，保留文字、图标和绑定中的加载反馈。

认证页面旧布局一直通过 WebGL 绘制全屏点阵，实测画布为 3840×1710。新增业务共享 AuthPageLayout，登录、注册、初始化和找回密码均切换到静态背景；成功状态使用短过渡并保留跳转回调，支持减少动态效果。长表单复用覆盖式滚动条，焦点外圈保持完整，出现滚动条时不挤窄表单。

4 倍 CPU 限速检查还复现了助手展开后首次点击被吞掉：透明保护层在动画结束后仍等待下一次指针事件。现改为仅在窗口转换期间拦截，转换结束自动解除，同时删除多余的指针状态和回调。

## 验证

同一 Chrome GPU 进程、相同视口、前台静置分别采样 8 次：分镜页原为 68%–72%，仅移除素材占位动画后为 13%–14%，再移除空闲波纹后为 0%；认证组件预览旧布局为 70%–74%，静态布局为 0%。这些是本机 Windows 性能计数器的样本。

Chrome 检查分集切换、资产搜索及子资产显示、助手鼠标和键盘打开收起、深色主题和主题还原。4 倍 CPU 限速下首次点击能正常收起助手。分镜页、资产页和仪表盘的 DOM 样式记录均未发现无限循环动画。

独立认证组件预览验证普通与减少动画模式的成功回调均只执行一次，检查桌面及 390×844 窄屏、长表单首中末项的焦点与校验边框、禁用状态。长短表单输入框宽度均为 334px，滚动条不占布局宽度。未退出用户账号或修改认证凭据。

TypeScript、修改组件的 ESLint、最终生产构建和 git diff --check 通过。测试用 CPU 限速、视口和媒体偏好均已恢复；临时预览服务已停止，项目原有前后端继续运行。
