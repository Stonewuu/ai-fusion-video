# 页面 GPU 与低配性能

检查打开页面后持续占用 GPU 的来源，以同一 Chrome 页面、相同视口下的空闲 GPU 采样、页面动画及渲染记录作对比。优先清除不表示加载或进度的循环装饰，减少模糊叠层和不必要的 WebGL 绘制，保留业务操作与状态反馈。

范围包含素材占位图、全局助手入口、分镜绑定提醒、认证页面背景，以及根据采样发现的其他持续渲染。复用现有 v-1.3.1，不改模型、业务数据、共享 components/ui 源码或用户浏览器设置。

验证分镜、仪表盘、资产与认证页面的空闲和交互状态，检查主题切换、窄屏和减少动态效果设置；运行 TypeScript 及与修改有关的检查。GPU 百分比仅代表本机相同条件下的样本，不作为所有设备的性能保证。
