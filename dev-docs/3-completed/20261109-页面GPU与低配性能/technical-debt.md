# 验证边界

GPU 数据来自本机 Windows 性能计数器对 Chrome GPU 进程的采样，反映相同页面和视口下的空闲表现。其他标签、桌面合成、分辨率及驱动会影响总占用；视频播放、画布操作和页面切换仍会按实际工作量使用 GPU。此次未修改系统图形设置或浏览器硬件加速。

交互检查使用本机和 4 倍 CPU 限速，不能等同于所有低配硬件。没有引入设备猜测、用户可见的性能模式或全局关闭动画的样式覆盖；保留正常的加载、进度及短过渡反馈。

认证验证使用直接引用同一业务布局的独立组件预览，检查渲染和成功回调；未对用户账号执行登录、注册或密码重置。四个认证业务页面均已接入新布局并通过生产构建。

共享 components/ui 下的旧认证及粒子组件未修改；业务认证入口已不再引用它们。测试附件和临时预览位于被 Git 忽略的 .local 目录，不进入发布产物。
