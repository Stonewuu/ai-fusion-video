# 维护边界

- 通用默认模板是用户明确要求的配置起点，不作为原厂已验证能力声明；有精确规格的型号优先使用独立预设。
- 供应商网关的可用性与接口权限仍以当前密钥和模型广场交集为准，原厂文档不代替供应商授权。
- 原厂已下线但供应商仍列出的模型保留供应商精确 ID，不擅自换成其他型号。当前资料注明 Step Image Edit 2、Veo 3.1 Preview 原厂入口已下线；不能据此推断供应商对应线路状态。
- 本次采用离线协议及本地界面验证，不能宣称每条付费线路都已真实生成成功。
- 原厂能力和供应商传输能力分开维护。无限星河当前公开 Videos 文档只明确单张 input_reference；尾帧、多参考素材的通道字段尚未确认。适配器在提交前明确拒绝这些尚未编码的输入，避免静默丢失；取得供应商明确合同后再实现并开放。
- 当前 44 个型号使用逐型号维护的赞助商预设；未来型号使用通用模板时，不会自动猜测或继承其他原厂的请求协议，需要有明确规格后补充该型号预设。
- 旧记录显式保存的 useProviderDefaultSize 仍按原来的平台默认协议执行；新预设提供完整选项。兼容对象仅为已有持久化覆盖配置，不重写用户主动配置的值。
