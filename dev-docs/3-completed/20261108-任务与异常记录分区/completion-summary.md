# 完成情况

运行与通知默认展示任务，异常记录通过独立页签和数量进入，历史异常不会挤占正常任务的列表空间。异常页可按待确认、执行失败、已取消以及全部时间、近 7 天、近 30 天筛选，每页 20 条，提供刷新和继续加载。

服务端在当前用户权限范围内先筛选再分页，分别返回全部异常数和筛选后的数量。查询保留现有任务状态及详情权限，不改变或删除历史执行数据。

任务列表、异常列表和两类详情分别保持选择及阅读位置。展开面板使用共享 Dialog，支持键盘、窄屏列表与详情切换；取消任务使用中性状态图标。拆分原来的大型面板文件，列表与查询状态独立维护。

验证通过：MySQL 集成测试覆盖权限、时间范围、统计和分页；Chrome 覆盖分类切换、筛选、详情、阅读位置、手机宽度、明暗主题和焦点；浏览器测试响应覆盖加载、失败重试、空结果以及跨页追加。测试响应已撤销，页面恢复本地数据。前端类型检查、相关 ESLint、生产构建和后端打包通过。
