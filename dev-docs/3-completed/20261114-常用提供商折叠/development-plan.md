# 常用提供商与二级弹窗

- 常用提供商默认最多展示 8 个，超过上限时通过“更多”弹窗展示完整目录。
- 赞助商优先，保留无限星河、秘塔、贰春的先后顺序；普通平台依次为 DeepSeek、OpenAI、ComfyUI、通义千问、MiniMax 国内/国际、火山方舟，其余保留目录顺序。
- 默认列表和弹窗复用提供商卡片及选择逻辑，保留赞助商快速配置能力。
- 业务弹窗统一使用共享内容容器，为嵌套弹窗补充独立遮罩；二级内容为实色，二级遮罩使用主题色半透明背景，不叠加背景模糊。全局确认框等独立 Portal 同样遵守二级样式。
- 保留组件库的焦点、Escape、外部点击及最上层关闭语义，不修改 components/ui 源码。
- 验证排序、默认数量、弹窗选择、滚动、明暗主题、窄屏及焦点安全空间，并执行前端静态检查。
