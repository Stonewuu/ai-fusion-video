# 开发计划

## 目标

修复 AI 任务中心打开历史 Pipeline 时，因持久化子工具结果缺少先行调用记录而导致页面抛出异常的问题。

## 实现范围

1. 调整历史消息到时间线的工具节点重建逻辑，按 `toolCallId` 合并调用与结果。
2. 支持结果先于调用、父工具节点后到，以及参数校验失败时仅保留错误结果投影的历史记录。
3. 保留工具 ID、工具名、参数等冲突校验。
4. 让事件清洗器识别字符串化 JSON，仅清洗其中敏感字段，避免整段工具结果被替换。
5. 让工具结果 JSON 视图兼容普通文本与脱敏占位符。
6. 增加覆盖根工具、子工具缺失调用、字符串化 JSON 清洗和文本结果格式化的回归测试。

## 验证

- TypeScript 类型检查。
- ESLint 检查。
- 前端历史重建与结果格式化单元测试。
- 后端事件清洗与运行时相关测试。
- 真实接口响应全量回放。
- 本地浏览器历史任务详情验证。
