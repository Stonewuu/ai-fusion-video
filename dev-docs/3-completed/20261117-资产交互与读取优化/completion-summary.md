# 资产交互与读取优化结果

窄屏默认显示完整资产目录，点击资产后从右侧滑出详情，“返回目录”关闭详情并回到原来的资产行；桌面仍保持左右分栏。目录始终挂载，保留搜索、分类和滚动位置；同一资产重新打开时保留子资产选择。深链接和新建成功后直接展示对应详情。

主资产和子资产的新建、编辑移入独立覆盖层。名称与外观在窄屏优先显示，“编辑图片”直接定位上传区；标题和保存区固定，正文可滚动。编辑弹窗嵌套在详情内，Esc 只关闭当前层，退出后恢复原入口焦点，保存成功更新选中对象。编辑结束后才切换宽窄屏的详情挂载位置，避免丢失草稿。保留还原、就近校验、上传与保存期间禁用、版本校验和请求幂等。

普通面板和内部分隔分别统一为 border-border/30 与 /20，保留选中与上传语义。页面入场使用 350ms 淡入和轻微上移，刷新不重播；切换、图片与反馈使用短过渡，减少动画模式直接展示内容。

资产读取优化包括：完整集合一次查询主资产、一次批量查询子资产；Agent 批量子资产摘要使用固定查询数量、每个资产独立分页，并只计算当前页的外观摘要。权限、完整响应、排序和父子版本保持原契约。分镜的剧本/分镜变化不再连带读取资产，资产事件单独刷新；手动刷新仍包含资产。生成结果添加到资产弹窗改用主资产列表。

## 验证

Chrome 在宽窄屏与明暗主题中完成截图、字段焦点、目录选择、编辑取消/还原/保存、新建、图片上传移除和状态检查；页面入场与内容切换采样确认有连续透明度和位移变化，刷新不重播。仅在本地验收项目创建和修改测试资产，没有创建生成任务。

目录默认展示后的补充验证覆盖 412 个资产列表的滚动位置保留、搜索分类保留、同一资产的子资产选择、嵌套编辑与删除确认的 Esc、新建及深链接打开详情、编辑草稿跨断点保留。320 与 390 像素宽度下详情没有横向溢出，768 像素使用右侧详情抽屉，桌面恢复左右分栏。

优化前 projectId=4 的一次刷新耗时约 4.96 秒，响应约 0.6 MB；只读统计为 412 个主资产、514 个子资产。后端隔离回归 16 项通过，包含 1 个与多资产查询数量不增长、完整数据一致性、分页与权限；前端类型检查、ESLint 和现有 7 项分镜刷新测试通过。

本次未重启服务，也未向业务后端 target 输出构建结果。运行中接口的优化后耗时未复测。
