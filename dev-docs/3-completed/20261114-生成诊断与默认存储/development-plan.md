# 生成诊断与默认存储

- 补齐本机 DEBUG 生成阶段和 HTTP 诊断日志；Docker 使用现有 docker profile，只输出 ERROR，两个镜像入口默认启用该 profile。
- 确定性配置错误立即结束任务；生成受理、提交前和结果入库的不同时间边界复用集中存储校验，避免无效配置仍提交付费请求。
- 无用户存储配置时由代码返回内置本地后端，使用 app.storage.local-base-path（默认 data/media）。不新增数据库配置记录，不执行启动补建，不新增迁移 SQL。
- 配置列表在零配置时显示内置默认项，无修改或删除入口，提示新增配置后切换；不使用容易误解为文件不可写的“只读”标签。
- 用户配置优先；删除最后一个用户配置后即时恢复内置后端。新增配置不移动或改写原文件，既有内置媒体仍可读取。
- 运行与通知展示通用任务上下文、时间和明确错误，不按具体错误增加定制操作。
- 统一生图提交错误提示与主内容宽度；通知详情突出错误及上下文。
- 验证配置失败状态流转、临时失败重试、原结果保存重试、日志分级与脱敏、零配置媒体保存及用户存储切换行为，完成后重新启动本地后端。
