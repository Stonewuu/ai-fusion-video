# 交付结果

零配置时直接使用代码内置的 data/media 本地后端，配置列表展示一个不可修改或删除的虚拟项；该项不写入数据库，不展示“只读”标签。用户新增存储后接管新写入，旧内置文件仍可访问；删除最后一个用户配置后立即恢复内置后端。无新增迁移 SQL，无启动补建配置，无文件迁移。

生成任务的确定性配置错误立即停止自动重试，临时保存故障保留重试能力，未知远端结果继续禁止自动重发。通知详情展示明确错误、模型、参数、提示词、时间、耗时与响应记录；生图提交错误提示与主内容统一宽度。

本地 DEBUG 增加生成与 HTTP 阶段诊断；Dockerfile 默认启用现有 docker profile，application-docker.yaml 只输出 ERROR 并关闭框架横幅。传输诊断不记录密钥、请求/响应正文或 URL 查询参数。

相关 79 个后端用例、前端 TypeScript/ESLint、差异格式检查及 clean package 通过。媒体集成测试最初因测试进程未找到 ffprobe 失败，指定真实 ffprobe 路径后通过。应用以 local profile 重启，接口 HTTP 200、Flyway 校验 37 条既有迁移成功。

Chrome 中用已有“重新保存结果”恢复了原图片任务，约 1 秒完成，1536×864 图片可正常显示；没有再次发起生成请求。另一条供应商配置已变化的历史任务保留原状态。本次未发布远端 Docker 镜像。
