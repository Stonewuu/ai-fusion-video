# 技术债务

- 内置本地后端以保留标识 0 写入媒体对象的 storage_config_id；storage_config 表不建立对应记录，现有用户配置使用正数自增 ID，现有媒体表无该配置表外键。后续新增读取、导出或清理路径必须通过统一后端解析，不能假设每个标识都对应配置行。
- 仅在没有未删除用户配置时启用内置后端；已有禁用或无默认项的配置明确报错，不自动改用其他存储。此行为来自明确的零配置与升级兼容需求。
- 使用既有 app.storage.local-base-path，保留历史 /media 路径与文件；新增用户配置后旧内置对象继续从原本地后端读取。部署时应延续既有本地媒体卷与目录设置。
- 本次没有数据库迁移、启动补建、数据搬迁或修改已有配置。历史配置仍按原 ID 使用。
- Dockerfile 与 docker profile 已调整；本次完成本地后端打包启动，没有发布远端 Docker 镜像。
