# 修复计划

修复资产生图智能体在失败后擅自移除参考图的问题，继续使用 v-1.3.1 分支。

1. 对照生成记录和工具调用，排除余额不足及文件丢失，确认参考图在哪一步被省略。
2. 在资产生成受理事务中，以同一执行任务首次受理的输入为约束，校验参考图顺序并沿用媒体版本，拒绝不一致请求。
3. 明确托管媒体地址的处理方式，修正基础子资产识别和失败重试提示词，禁止审核拒绝后自动改为纯文生图。
4. 验证参数省略、空列表、部分删除、替换、重排、恢复执行、版本变化与其他生成入口，确认拒绝发生在创建付费任务之前。

不修改现有图片或分镜，不调用供应商来重复生成；使用本地数据库和模拟边界验证重试约束。
