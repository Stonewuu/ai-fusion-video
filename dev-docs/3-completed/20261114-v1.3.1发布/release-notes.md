# v1.3.1 更新日志

- **生成工作台。** 支持按模型能力上传和预览图片、视频、音频参考素材。“再次使用”可恢复原模型、提示词、参数及参考素材；优化画幅、分辨率、数量和时长控件，长提示词在输入框内滚动，不再撑满页面。

- **任务进度与错误提示。** “运行与通知”将任务和异常记录分开展示，支持按状态、时间筛选。详情补充模型、提示词、生成参数、处理阶段、耗时和响应时间。存储或连接配置错误及时提示，已收到但未保存成功的结果可重新保存。

- **素材管理。** 媒体素材支持“仅从素材库移除”和“解除引用并永久删除”。删除前可查看引用范围，运行中的任务或无权修改的引用会阻止永久删除，避免误删仍在使用的文件。

- **默认本地存储。** 未配置存储时自动使用本地 `data/media`，设置页显示内置默认项，无需手动创建。添加自定义存储后使用用户配置，已有本地媒体仍可读取。

- **融光助手与长任务。** 助手顶部新增“新建会话”按钮。完善长剧本和长工具结果的分段读取、分镜按集查询及生成任务等待；临时网络故障可在原任务中重试，减少重复执行已完成步骤。

- **分镜与画布生成。** 首尾帧生成结合镜头关联的场景、人物和道具参考，支持仅修订提示词，再次生成时复用已保存的提示词。修复资产生图重试丢失参考图、画布视频提示词遗漏镜头要求等问题，统一画布生图的比例与分辨率设置。

- **编辑体验与性能。** 优化分镜表格列宽、行内编辑、首尾帧预览和可收起的详情栏，修复横向滚动时表头不同步。改善侧栏响应，减少不必要的模糊与重绘；二级弹窗改用实色内容和半透明遮罩，点击外部仅关闭最上层弹窗。
