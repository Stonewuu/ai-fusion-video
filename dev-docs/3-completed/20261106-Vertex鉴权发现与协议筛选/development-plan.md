# 开发计划

排查本地 Vertex AI 接入，支持服务账号与 API Key 两种鉴权方式，补齐自动获取模型，并限制赞助商专用协议只能在相应渠道使用。

1. 核对官方接入说明、当前 Google Cloud 项目、已保存凭据和 Java 直连／Clash 代理连通性。
2. 分离服务账号（项目 ID、地域、JSON 凭据）与 API Key 的连接配置，明确各自请求地址和鉴权，不静默切换方式。
3. 实现官方 Model Garden 列表分页与模型类型识别，保持错误可见，不以硬编码目录伪装远程发现。
4. 按 API 提供商过滤模型及 API 默认协议选项，同时在后端校验，防止绕过界面保存不匹配协议。
5. 通过单元测试、现有凭据的接口调用和 Chrome 页面验证两种鉴权、模型获取、调用、表单与协议筛选。

复用 v-1.3.1 分支。保留之前参考图修复的工作区变更；不修改 Google Cloud 权限、密钥限制、账单或本机系统代理。
