# 交付结果

共享虚拟目录按稳定 ID 测量高度并保留焦点与拖动项；剧本分集行独立复用，消除选中时重复读取场次。分镜目录只加载当前或展开的场次。表格与卡片共用主滚动区，保存中、失败草稿、焦点及拖动行离开视口后仍保留。

目录标题共用单个工具提示，固定定位、忽略指针命中并放在标题上方。悬停效果保留，行内操作不被遮挡，已离开视口的锚点不会留下浮层。侧栏与场次列表展开支持 200ms 过渡和减少动画偏好，窄屏复用同一入口。

验收使用独立本地项目：1505 集剧本目录从 48211 个页面元素降到约 700 个，目录通常挂载 20 至 25 个分集；1000 集、600 镜头分镜表格通常挂载 10 至 16 个镜头，卡片首次挂载 12 个。批量分镜目录接口在本机一次测量返回 1000 集耗时 66ms，旧逐条查询约 4 秒。此数值为本地样本，不是跨环境性能承诺。

Chrome 检查了桌面、390px 手机、760px 窄屏、目录首尾、拖动排序、焦点保留、悬停提示、跨场次定位、侧栏动画及明暗主题。特意提交过长镜号产生校验失败，失焦并滚出视口后草稿仍保留，取消后释放。页面高度保持视口高度。

生产构建、TypeScript 和相关逻辑测试通过。未调用图片、视频或付费语言模型；未改用户项目内容。
