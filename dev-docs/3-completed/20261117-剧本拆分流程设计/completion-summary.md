# 剧本拆分流程设计

## 已完成

1. 导入原文：上传与粘贴使用独立标签，上传文件显示字数、有限原文预览和编码；拆分规则作为辅助设置，字数错误就近提示。
2. 检查分集：正文占主要区域，目录支持标题或集数搜索、重名筛选和虚拟滚动；标题重名提示放在对应字段下，拆分、合并与删除靠近正文。
3. 确认导入：导入方式、替换提示与导入按钮固定在底部；窄屏目录可收起，按钮不足一行时自动换行，保留焦点与减少动画设置。

返回原文后保留已调整的标题、分界与删除结果，原文或规则变化时重新识别。保留容量、版本、幂等、替换确认及删除撤销规则。未修改共享 UI 组件或后端接口。

## 验证

Chrome 检查宽屏和两种窄屏、明暗主题及字段焦点、禁用和错误状态。使用约 69 万字、1,500 章的测试文件检查虚拟目录与搜索，滚动不撑高页面。编码切换、目录选集、重名定位、手动拆分合并、删除至空和撤销、返回步骤以及替换确认均已操作检查；在本地验收项目追加导入整理后的单集成功。

导入逻辑测试 7 项及 TypeScript 检查通过；ESLint 无错误，有一条 TanStack Virtual 的 React Compiler 兼容性提示。生产构建通过。
