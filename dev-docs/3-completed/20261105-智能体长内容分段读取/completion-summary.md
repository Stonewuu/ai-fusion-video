# 智能体长内容分段读取交付

## 最终范围

在 v-1.3.1 完成剧本与分集原文、通用长工具结果的受控分段读取。替换 AgentScope 默认“保存全文后要求调用 read_file”的处理，模型获得的读取入口与实际工具清单一致，不开放服务器文件路径。

## 关键实现

- 剧本查询通过 contentReads 返回正文位置和内容版本，read_script_content 按业务对象读取原文，每次重新检查权限。画布专业节点同时限制当前项目范围。
- 默认每段 4,000 个 Unicode 字符，最大 8,000 个；返回 offset、endOffset、totalChars、nextOffset、hasMore。中文、补充字符、无换行长文本、空正文和末尾范围均有明确行为。
- 内容版本取原文摘要，继续读取时必须提交。场次修改导致父级业务版本变化时不误报正文变化；正文变化则拒绝拼接新旧内容。
- 通用长结果以内容摘要作为不可变结果编号，按可信用户和会话隔离。完整保存成功后才替换会话状态及模型输入，保留附件、工具状态和元数据；read_tool_result 只能读取当前会话的结果。
- 读取工具作为返回读取入口的工具依赖自动登记，覆盖主智能体、子智能体和用户指定的工具子集。未启用工具的智能体保持无工具。解析提示词要求按连续范围处理，不能把分页或首尾预览当作全文。
- 长结果文件先保存，随后用短事务检查存储位置、登记正文和媒体引用。拒绝外层事务，处理并发重复保存、存储切换和数据库提交回执丢失。

## 验证

- 87 项后端回归通过，无失败、错误或跳过；后端生产打包通过。
- 使用确定性的模拟模型运行完整 AgentScope Harness 工具循环，连续读取并逐字还原 95,910 字符文本。另验证含补充 Unicode 字符的长篇单行剧本。
- 使用隔离 MySQL、Redis 和本地文件存储验证应用装配、持久化恢复、并发去重和异常提交。慢文件写入期间，另一连接仍能取得同一配置行的写锁。
- 验证原文权限撤销、画布项目边界、跨用户与跨会话读取拒绝、非法分页、正文版本变化、保存失败不调用模型，以及旧任务工具契约检查。
- 应用启动时数据库迁移校验通过。本次复用既有工作空间结构，没有新增迁移。

## 升级与边界

工具协议更新为 afv-tools-v3。旧协议的进行中任务需要重新发起，已保存的剧本、分集和场次保留。测试没有调用付费模型，不能据此认定某个供应商模型已完成整篇小说的剧情分析。本次完成代码、验证和后端打包，未发布正式版本。
