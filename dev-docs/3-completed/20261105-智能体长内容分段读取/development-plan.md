# 智能体长内容分段读取

## 范围

在 v-1.3.1 分支修复长工具结果仅保留首尾内容、却没有可用读取工具的问题。原文完整保存，模型通过有权限边界的工具分段读取，不开放服务器文件路径。

## 实现安排

1. 增加统一文本分页协议，包含内容版本、读取范围、下一段位置及结束标识，限制单次返回量并正确处理 Unicode 字符。
2. 剧本与分集原文按业务 ID 读取，每次检查当前权限及原文版本；查询工具返回正文的读取入口。
3. 超长工具结果保存到现有工作空间，按用户与会话隔离，以不可变结果 ID 读取。替换 SDK 默认截断机制，保留工具错误、附件和状态。
4. 补齐主智能体、子智能体与画布节点的读取工具、提示词和工具契约；未启用工具的智能体保持无工具。
5. 验证全文连续读取、版本变化、越权、缺失结果、存储故障、工具注册和运行时衔接。

## 验证原则

重点测试会丢失正文或越权的边界，以及已安装 SDK 的集成行为。使用确定性的模型响应验证工具链，不调用付费模型。数据库和存储验证使用隔离测试资源。
