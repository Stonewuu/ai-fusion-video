# 范围与维护边界

- 图片、视频使用独立 `youkou` 协议，没有请求失败后切换协议或默认换模型的逻辑。
- 对话配置明确设置 `sendIncludeReasoning=false`，适配当前合同只公布 `reasoning_effort` 的情况。该选项只控制是否发送 `include_reasoning` 扩展字段，既有提供商继续使用原有配置行为；后续合同变更时需重新核对。
- 模型能力保存为快速配置时读取的合同快照。平台参数变化后需显式更新模型配置；快速添加仍保留已有模型，不自动覆盖用户的设置。
- 当前使用已公布的单文件 `POST /v1/media/uploads` 上传参考素材。可选的 v3 对象存储直传未接入。
- 音频生成、独立视频处理或超分、账户余额、充值和反馈入口不在本次功能范围。没有完整生成规格的目录条目不允许快速添加。
- 首次供应商联调完成一张文生图和一段文生视频；后续“视频引用与贰春复验”完成一段参考视频生成，Grok 图生视频则由供应商标记失败并全额退款，没有视频结果。该渠道图生视频效果尚未验证成功，具体失败原因未披露。图片编辑、多素材视频、任务拒绝和网络中断另有本地 HTTP 模拟服务测试。文本通过本地 Chat Completions 流式协议测试，未额外消耗额度调用文本模型。
- 后续复验已删除配置生成器误加的 `maxCount: 1`，工作台批量结果沿用既有任务拆分与排队机制；本地四个模型通过配置页修正。

本次没有新增数据库迁移，没有安装供应商的 Agent Skill、CLI 或画布，也没有把密钥加入源码、测试样例或提交记录。
