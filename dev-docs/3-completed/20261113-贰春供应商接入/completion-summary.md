# 贰春供应商接入完成

## 交付范围

版本归属为 1.3.1，仍处于开发阶段。新增「贰春 AI」赞助商和快速配置入口，支持按当前密钥读取对话、图片、视频模型及其参数。API 默认根地址为 `https://api.youkou.cc`，由配置追加 `/v1`。提供商入口及获取密钥链接已在 Chrome 中核对。

供应商图标及中英文 README 使用[贰春官网](https://erchun.youkou.cc/)公布的「贰春科技」Logo，原图保存为前端静态资源与 README 赞助商资源，页面加载不依赖外部图片地址。「常用提供商」前三项按无限星河 AI、秘塔 AI、贰春 AI 展示。

文本请求复用 Chat Completions，按目录保存上下文长度、思考等级和多模态输入能力，不发送平台未公布的 `include_reasoning`。图片和视频通过独立 `youkou` 策略处理 HTTP 202、任务编号、模型身份和状态；图片完成后请求独立结果接口，视频完成后读取带鉴权的文件接口。

参考素材通过平台单文件上传接口转换为 `media_id`。请求参数、数量、格式、尺寸、时长及混合素材约束按对应模型合同校验。供应商地址由已配置的 API 根地址构造；下载跳转到签名地址后停止携带 Bearer，即使跳转目标同域。

生成请求及唯一幂等标识在付费提交前进入现有执行意图。提交只执行一次；状态未知时保留原任务，不自动重建。任务调度支持超过一分钟的 `Retry-After`，等待不超过任务截止时间。

## 验证与费用

- 52 项相关后端用例分批通过，包括 MySQL 配置保存、并发任务与轮询时序测试；前端类型检查、ESLint、2 项协议选项测试通过。
- 本地应用重新打包启动成功，37 条 Flyway 迁移验证通过，本次没有修改数据库迁移。
- 通过新增 Java 实现调用供应商接口，各生成一次图片和视频，完成任务查询与文件下载。图片为 1024×1024 JPEG；视频为 854×480 MP4、4.04 秒。
- 用户批准的两次生成净扣费合计 1.302 credits，已通过消费接口核实。没有额外生成重试。
- Chrome 验证提供商入口、空值与无效密钥提示、加载禁用、焦点边界、桌面及窄屏、明暗主题。

## 使用与后续

刷新本地页面，在「AI 配置 → 添加 API 配置 → 贰春 AI」填写平台密钥并读取模型。模型列表按当前目录展示，未公布完整规格的模型会说明限制。

本次没有修改用户已有的 API 配置，也没有发布正式版本。音频、独立视频处理与超分、v3 直传及平台账户管理接口留在本次范围之外。多素材上传与图片编辑通过模拟协议验证，供应商生成联调范围限于已授权的文生图和文生视频。
