# 贰春供应商接入

## 版本与范围

- 前后端版本保持 1.3.1。2026-11-13 已核对远端正式 Release 和 Tag，最新发布为 v1.3.0，1.3.1 尚未发布。
- 在提供商目录增加贰春赞助商，沿用现有快速配置入口，按当前密钥读取模型目录和参数。
- 对话使用 Chat Completions；图片、视频使用独立的 Youkou 异步协议。保留现有生成任务调度、提交意图、结果托管和权限检查。
- 根据逐模型合同传递参数及参考素材，完成任务状态查询、图片结果读取和视频文件读取。
- 不安装供应商的 Agent Skill 或本地画布，不把接入码或 API Key 写入源码、文档及测试用例。

## 实施顺序

1. 核对当前账号目录、能力字段与公开合同，确定可直接配置的模型。
2. 增加提供商目录、模型发现与参数映射。
3. 实现素材上传、请求准备、幂等标识、异步结果和错误处理。
4. 增加针对外部协议、参数组合和重复提交风险的测试，检查现有供应商回归。
5. 完成前端检查、Chrome 页面验收和开发文档。

## 验证要求

- 使用本地 HTTP 模拟服务检查请求路径、鉴权、参数、202 回执、状态变化和结果获取；模拟拒绝、未知状态和网络中断，确保不会重复创建任务。
- 使用供应商接口读取模型、目录、价格，核对发现结果。生成调用的模型、规格和费用需先明确。
- 前端检查提供商展示、快捷配置、协议选项及错误状态。新增或调整表单布局时按项目规则检查焦点、滚动和窄屏。
