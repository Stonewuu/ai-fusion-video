# 技术债务与边界

- 本次不引入兼容 fallback，不改变工具和子 agent 定义。
- 明确 HTTP 错误可结束本地等待；真正断流、取消或失去执行归属的未知请求仍保留核实机制。
- 保留现有管理员核实权限和审计，调整入口位置，不自动伪造远端结束证据。
- 当前画布选中的本机模拟模型只实现特定验收协议，不能代表真实模型支持专业分镜任务。
- 测试环境默认视频模型声明不支持首帧/参考图片；未伪造能力声明或将图片偷偷转为文字。选择真实图生视频路径时仍需配置支持相应输入的模型。
- 请求表的 COMPLETED 表示 HTTP 请求生命周期结束，不代表 Agent 成功。明确 HTTP 错误对应的用量记录和 Agent 保持 FAILED，无需新增数据库状态或迁移。
- 节点在执行中显示的媒体仅用于预览；下游解析仍要求前置节点成功，不提前触发生成。
- 不确定远端调用的核实权限和审计保持原有规则；本次改善入口，不扩大非管理员权限。
