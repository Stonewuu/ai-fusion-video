# 1.3.0 迁移合并与发布准备

## 范围

- 远端最新正式版本为 v1.2.0；1.3.0 尚未发布，允许在发布前合并本版本的 38 个开发迁移。已发布的 V、B 文件内容和文件名保持不变。
- 按关联功能合并文件；新建表直接包含最终字段、索引和约束，已有表尽量一次 ALTER 完成相关变更，视图只保留最终定义。保留正式版本升级所需的数据处理与执行顺序。
- 验证旧脚本与合并脚本的最终结构和数据结果，并验证全新安装、从 v1.2.0 升级以及 Flyway validate。
- 用户已明确要求同步本地迁移状态：先备份 ai-fusion-video-mysql 中的 ai_fusion_video 数据库，再确认结构一致并替换本版本的开发迁移历史，保留业务数据及已发布版本历史。
- 检查本次 1.3.0 开发代码与待提交文件，沿用已有版本分支的命名方式，完成必要检查后提交并推送到 v-1.3.0 分支。此任务不发布正式 Release、Tag 或镜像。

## 顺序

1. 核对发布状态和本地迁移记录，保存原脚本供对照。
2. 合并迁移，调整依赖旧开发版本边界的测试。
3. 对比结构、索引、约束、视图及数据处理，运行后端、前端和相关迁移检查。
4. 备份并同步本地数据库迁移历史，重新启动后端验证。
5. 整理交付记录，提交并推送 v1.3.0。
