## v1.3.0 更新日志

- **新增无限画布。** 剧本、分镜、角色和素材可以放在同一张画布上。画布可一键整理，常用流程可存成模板，也支持多人编辑、评论和保存版本。

- **融光助手。** 回复会随着生成逐段显示。刷新页面、断线重连或切回之前的对话，都能接着看。现在还可以为自己使用的智能体设置常用指令、工具和默认技能，也可以给画布中的某个智能体单独选技能。

- **视频生成。** 新增 Seedance 2.5、MiniMax H3 系列和万相 3.0 系列。配置对应服务后，选择模型即可看到它支持的时长、画幅、声音和参考素材选项。

- **多图参考与 ComfyUI。** 使用 ComfyUI 创作时，页面会显示当前工作流需要哪些素材、最多能放几张参考图。例如，工作流提供四个参考图位置，就可以同时传入两张角色图和两张场景图。漏传必需图片或超过数量上限时，生成前就会提示。

- **任务进度与重试。** 提交画布任务后可以先离开页面，回来再看进度和已完成的结果。生成中断时，系统会自动检查任务状态，处理结果可在顶部「运行与通知」里查看。画布运行失败后，可以先查看哪些步骤需要重做。对于已成功的步骤，只要素材和设置没变，就可以沿用上次结果。

- **团队与账号。** 加强了团队、项目和素材的权限检查，修复成员被移出项目后仍能删除生成记录的问题。已移出的团队成员可以重新邀请，并按新分配的角色加入。模型密钥等敏感设置仅对系统管理员开放。

- **编辑体验。** 切换同一模块的侧边菜单时，只更新当前内容。编辑长资产设定时，可以滚动查看后面的子资产。修复了剧本解析和分镜编辑时输入框边缘被截断，以及手机上部分工作流按钮挤出屏幕的问题。
