# 生成工作台输入与执行详情

两项修复已在本地生效，刷新页面后可使用。

## 输入框

简洁模式原来随内容增高且没有上限，908 字提示词在 Chrome 中将输入框撑到 1548px。现在保留自动增高，但最高不超过 256px 和视口高度的 30%；高级模式最高不超过 288px 和视口高度的 30%。超出部分在输入框内滚动，保留内侧间距。图片与视频工作台共用这套布局。

根据后续边框反馈，已撤回此次新增的输入框独立边框与焦点圈。编辑区和外层输入面板共用一套边界与聚焦反馈，避免叠出内外两圈；限高和滚动行为不变。

再次核对发现，全局表单底色规则覆盖了 Tailwind 的透明背景，新增的内层容器使直角白底显露出来。已恢复原有输入区结构与内边距，只在这两处编辑区将 `--field-background` 设为透明。Chrome 确认普通、聚焦和长文本状态下没有独立白底与内圈，长文本仍保持限高；未修改共享 Textarea 或全局表单样式。

## 执行详情

详情新增完整提示词及复制入口、生成参数、参考图片和视频预览、创建与更新时间、每次准备/提交/回执时间、供应商任务编号。模型协议、错误代码、任务编号、执行编号、查询次数和原错误信息放在诊断区。已收到同步结果但没有异步任务编号时显示“—”，不误报未收到响应。

后端读取已有执行快照和时间字段，公开输入字段按用途限定，不返回执行上下文、模型配置或鉴权信息。多组结果的数量按全部结果计算。权限检查仍在读取详情之前完成，不新增数据库迁移。

对本地处理已结束但没有供应商回执的任务，详情显示“受理待确认”，并提供核对供应商任务的下一步。这次截图中的任务已记录 09:04:25 发起提交、09:06:04 最后更新，但没有回执，无法据此补出供应商具体报错。
