# 工具结果与分集标题展示

## 范围

- 为分段读取剧本、分段读取工具结果补齐中文名称、读取范围、总字数、是否到达末尾和按需展开的正文。
- 同步适配剧本查询返回的正文读取入口，避免只显示通用提示；通知面板和工作流工具结果保持一致。
- 分集目录标题在未悬停时使用右侧空间，悬停或键盘聚焦时显示操作按钮，并用 Tooltip 展示完整标题。
- 点击场次后等待正文挂载，再仅滚动正文容器，让场次标题显示在顶部；动画为 0.5 秒，可被下一次选择或手动滚动中断。
- 分镜及子资产预处理的提示词明确默认使用已解析场次，不再把原文入口作为必要输入；区分前端“工具结果内容”和“原文”文案。

## 验证

测试分页范围、空正文、末尾读取和错误结果，避免把读到末尾误报为全文已处理。运行前端类型检查、相关回归和构建，并在 Chrome 检查工具卡片、标题悬停、键盘聚焦和窄屏布局。
