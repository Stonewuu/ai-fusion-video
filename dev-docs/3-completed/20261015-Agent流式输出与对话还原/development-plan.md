# Agent 流式输出与对话还原

## 目标与范围

参考 `D:/develop/my/agenteam-package/agenteam` 的 AgentScope 接入，实现模型增量及时显示、运行中刷新/切换/断线恢复一致、主 agent 与子 agent 默认不限执行时间和步数。保留现有工具及子 agent 的定义方式，不引入沙盒、命令执行、文件操作能力。

## 实施顺序

1. 对照模型适配、事件发送/保存、对话还原、前端消费四条链路，记录造成等待和批量输出的明确原因。
2. 恢复真正的模型流式传输，保留一次提交、取消、用量登记等已有正确性约束；移除等完整回复才发送的缓冲。
3. 改造实时事件发送与保存关系，保证顺序、刷新接续、子 agent 事件归属和终态一致。
4. 修复前端增量处理、恢复、连接生命周期和渲染节奏；移除主/子 agent 的默认总时间及步数限制，保留用户取消、租约和网络故障检测。
5. 用延迟分片、慢数据库、断线、刷新、并行子 agent、取消和终态测试验证；执行必要后端/前端检查，通过 Chrome 验证真实页面。
6. 按用户补充要求升级到 agenteam 实际使用的 AgentScope 版本：参考仓库 `agenteam-server/pom.xml` 当前为 **2.0.4**；本仓原为 2.0.0。升级全部 AgentScope 模块，重新核对 API、运行时行为和针对性测试。

## 完成依据

- 第一段模型内容在模型完成前可到达浏览器；持续输出无全回复收集或数据库等待导致的突发吐字。
