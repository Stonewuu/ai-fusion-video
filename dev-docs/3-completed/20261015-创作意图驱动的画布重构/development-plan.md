# 创作意图驱动的画布重构

## 目标

以用户的创作目标、实际素材和模型能力组织画布。文字、资产、图片、分镜和视频可组合，分镜、先图后视频均为可选路径。保留工具与子 agent 的定义方式及已有流式、恢复和媒体预览能力。

## 实施范围

1. 建立明确的素材输入契约：内容设定接受文字与业务资源，视觉参考保留真实媒体类型；服务端固定原输入、生成最终提示词并验证类型和权限。
2. 生成图片、视频和文本可直接使用资产或其他内容，无需先建立分镜。前后端连接建议、批量配置与模型能力校验遵循相同契约。
3. 在节点编辑区显示连接来源、用途和状态，允许原位连接、定位和移除输入；运行前展示实际路径和待处理问题。
4. 画布 Agent 规划遵循用户目标与模型真实能力，明确素材用途，不擅自改变流程或虚构模型能力。
5. 画布执行采用自动批准策略并传递至子任务；保持真实授权、作用域、费用范围与不确定远端请求的状态语义。
6. 验证资产直接生视频、文字与资产组合、图生视频、分镜链路、批量与结果复用、自动执行和错误恢复；更新本地服务并使用 Chrome 验收。

## 验收边界

不伪造图生视频能力，不用文字替代图片输入来宣称消费了图片，不通过重发未知远端请求恢复任务。新输入通过明确契约实现，不增加兼容 fallback。
