# 技术债务与边界

- 本次不改变工具、子 agent 注册和定义方式，不新增沙盒、命令执行或文件操作能力。
- 使用现有节点配置与运行快照保存契约，不以直接修改历史任务或迁移来掩盖语义差异。
- 自由组合仍受所选模型真实输入能力约束；能力不足应在当前节点明确呈现并允许调整。
- 画布自动批准使用平台现有策略；外部调用状态核实不是工具审批，不伪造远端完成。

## 完成后的边界

- 无新增兼容 fallback，无新增数据库迁移。联合类型只用于输入，输出保持单一实际类型。
- FULL_ACCESS 仅适用于已受理画布专业节点及其子任务；交互助手仍遵循用户显式选择的执行模式。作用域、白名单、对象版本与数量预算继续由服务端校验。
- 默认取消智能体与画布总时限和智能体步数限制；媒体处理、单次网络请求和模型上下文长度仍遵循各自实际契约，不等同于智能体总执行时长。
- 恢复入口复用仍为 CURRENT 的成功节点。输入已变更的依赖需重新计算；部分完成节点按整体重新执行，界面明确提示并先展示数量计划，不承诺复用其内部每个生成项。
- 用户当前生图/视频模型仍为本机模拟服务；Chrome 中的纯色图片与彩条视频是测试媒体，不能视为真实创作效果。集成测试使用本机供应商与隔离数据库，不伪造线上模型能力。
- 原首帧主任务的历史 400 发生在并行恢复修复部署前。保留原失败记录与已提交媒体，未为了将状态变绿重新调用模型或篡改历史。
- 单条模型消息含多个 ToolResultBlock 会被 AgentScope 2.0.4 的 OpenAIMessageConverter 取首项。平台现在从恢复边界明确构造每个结果独立的 TOOL 消息；实际转换器与持久化 SDK 集成测试防止回归。
