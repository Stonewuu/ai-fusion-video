## 最终范围

文字、资产、剧本、分集、场景与分镜可作为生成内容设定直接组合，生图、生视频、生文本及 ComfyUI 不再要求一条固定分镜链路。图片、首尾帧、视频与音频保留明确的媒体输入，内容设定不会隐式提取图片冒充视觉参考。

节点编辑区增加输入与来源管理，支持选择、替换、定位和移除连线；并发编辑使用节点和连线版本保护。运行计划展示真实依赖与输入用途。媒体仍在节点内预览，运行中和刷新后均从持久化输入/结果重建。失败运行可先复用未变化的成功节点并预览需重做范围。

画布专业主任务与子任务采用自动批准；恢复旧任务也采用相同运行策略。工具定义、子 agent 定义和注册方式保持原有结构。总执行期限使用已有配置，默认不限时，移除画布六小时硬编码；主、子 agent 的步数仍按上一阶段完成的无限制配置执行。AgentScope 保持与 agenteam 对齐的 2.0.4。

## 实测发现与修复

1. 多个子任务持久化恢复时，多个工具结果被合并为一条 Msg，OpenAI 转换器只取第一项，真实 DeepSeek 返回缺少 tool_call_id 的 HTTP 400。修复为每项结果独立 TOOL 消息，保留顺序、内容和成功/错误状态，并拒绝重复工具身份。
2. 专业智能体内的生成请求未显示在节点详情中，导致状态待核实却找不到操作入口。现在显示所有实际生成请求、模型和状态，并在节点内复用既有执行核实/重试界面与授权审计。生成未结束时，不因父任务文本结束而停止观察。
3. 本机测试依赖已退出导致后端启动失败、模拟生成请求无法连接。恢复原 MCP 和模拟生成服务，按记录核实明确未发出的请求与已停止的历史等待，未盲目重发未知请求。
