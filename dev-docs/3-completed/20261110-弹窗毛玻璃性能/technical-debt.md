# 验证边界

GPU 采样按 Chrome GPU 进程汇总，属于本机观察值。对比需要保持窗口、页面、弹窗内容与交互方式一致，区分打开动画、静置和操作期间的数据。

保留实际 backdrop-filter 效果，不能仅通过提高背景不透明度将毛玻璃变成实体表面。未进行硬件加速、代理或浏览器安全设置调整。

用户选择保留整屏毛玻璃。当前已降低静置和连续滚动开销，但高分辨率、大内容弹窗的连续滚动仍占用约 60%～80% GPU，不能宣称低配设备的全部卡顿已经解决。无模糊对照也有约 50% 占用，后续若继续优化，需要分别检查长时间线内容与浏览器合成开销，而不是继续堆叠滤镜或强制图层提升。

Windows GPU 引擎计数器偶有超过 100 的读数，记录中保留原值，结论只表述为接近满载。采样针对 Chrome GPU 进程，不等于某一个组件的独立消耗；本次没有测量 FPS，也没有在其他显卡上验证。控件验证使用项目共享组件的隔离页面，不代表逐个业务弹窗都已验收。
