# 弹窗毛玻璃性能优化

2026-11-10 在 v-1.3.1 工作区完成，尚未发布。用户明确保留整屏毛玻璃。

## 最终实现

全屏遮罩保留 2px 模糊和原有透明度，弹窗本体及内部卡片共用这层背景效果，取消重复背景滤镜。遮罩存在时暂停助手波纹，关闭最后一个遮罩后接着播放；前景加载动画、弹窗进出动画和 Portal 菜单保持原有行为。修改集中在全局样式，未修改共享 UI 组件源码。

## 验证结果

项目“运行与通知”弹窗在 1920×855 CSS 视口、DPR 2 下验证。原效果静置接近满载，最终效果六次静置采样均为零。同样速度和距离的连续滚动对比中，8px 整屏模糊均值约 95%，2px 方案约 72%（61%～82%）。无模糊对照约 51%，说明长内容滚动本身也有开销。

生产构建及 TypeScript 检查通过。Chrome 验证覆盖浅色桌面、深色窄屏、长表单首尾及中间项的焦点、校验、禁用状态，以及嵌套弹窗、下拉选择、侧边弹窗、自定义模态层和前景加载动画。关闭项目弹窗后三个助手波纹恢复播放；临时样式和视口覆盖已恢复，隔离验证服务已停止。

## 使用与限制

本地开发页面已加载修改，前后端服务保持运行。没有修改项目数据、模型配置或浏览器硬件加速设置。GPU 数据只代表本机 Chrome 进程采样；大内容弹窗连续滚动仍有较高开销，尚不能据此承诺所有低配设备都流畅。
