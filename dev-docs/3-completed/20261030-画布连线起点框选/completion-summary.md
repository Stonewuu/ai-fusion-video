## 问题与处理

选择模式的普通框选要求按下位置直接落在画布背景。连线及数字标签会接收按下事件，因此从这些位置开始拖动时没有初始化框选。

新增连线拖动识别：在选择模式下记录鼠标按下的位置，移动达到 4px 后，将起点和当前移动事件转交给画布容器，后续由 React Flow 的框选和指针捕获处理。没有达到拖动阈值时不拦截事件，单击连线仍可选中和查看。连线端点的重连手柄、Shift 框选、触摸和移动模式沿用现有行为。

## 修改范围

- `components/canvas/editor/use-edge-marquee.ts`：识别从连线开始的拖动并转交框选，松开、取消或离开区域时清理未开始的手势。
- `components/canvas/editor/canvas-flow.tsx`：仅在选择模式且未按住空格时启用处理。
