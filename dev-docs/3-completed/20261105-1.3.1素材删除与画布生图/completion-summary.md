# 1.3.1 素材删除与画布生图交付

## 最终范围

- 媒体素材库和生图参考图均可打开删除弹窗，查看引用范围，选择仅从素材库移除或解除引用并永久删除。
- 仅移除保留文件及媒体版本。永久删除清理当前画布与项目引用、断开下游连线、处理派生预览、撤销访问凭据，并保留历史中的删除状态。
- 删除操作重新检查当前权限和引用范围。运行中的任务、系统预设及无法修改的引用阻止永久删除；独立副本保留，最后一份有效副本删除后才清理共享文件。
- 物理文件清理由持久化任务在事务外执行，使用已有跨实例文件锁，失败自动重试。界面和重复请求均区分待清理与已删除。
- 画布生图复用工作台的比例、分辨率控件及参数处理。切换比例或模型时保持合法组合，清除冲突宽高，并保留模型要求的档位或像素提交格式。运行前拒绝不合法组合及尺寸。

## 版本与数据库

分支为 v-1.3.1，前后端版本统一为 1.3.1。创建迁移前核对正式 v1.3.0 Release/Tag 及空的验收数据库。新增 V1.1.3.1.0__add_media_deletion.sql，登记素材删除和文件清理任务；既有发布迁移保持原样。迁移命名检查、从旧版本升级和应用启动时的 Flyway validate 均通过。

## 验证结果

- 前端：88 项回归、TypeScript、修改文件 ESLint、Next.js 生产构建通过。
- 后端：61 项不同用例通过，包含素材删除、重复请求、当前权限撤销、并发新增引用、派生预览、共享文件、存储故障重试、MinIO 文件删除及慢 I/O 不持有数据库事务。
- Chrome：桌面及 390px 窄屏，明暗主题，首项与末项、聚焦、错误及禁用状态，比例和档位联动、自动尺寸、模型切换、删除弹窗及参考图两种删除结果均已检查。
- 应用联调：通过应用 HTTP 接口和本地模拟图片服务，确认画布 9:16 / 2K 请求发送 1152×2048 并完成生成；1920×1080 在运行前被拒绝。删除后引用和下游连线清除，后台文件任务达到 PURGED。

## 边界

没有调用付费图片供应商接口。历史审计记录保留，不再允许读取或恢复已永久删除的媒体；外部 URL、已经下载的文件及用户备份不属于素材库文件删除范围。本次完成开发和验证，未发布正式版本。
