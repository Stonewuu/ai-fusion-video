# 维护约定与验证范围

- 已发布的 1.3.0 及更早数据库迁移不可修改。
- 删除操作不得破坏已有业务内容、画布版本、生成任务或共享文件副本；文件 I/O 不得持有数据库事务或行锁。
- 复用现有模型能力配置，不为缺失配置补造供应商支持的比例或尺寸。
- 原素材及派生预览共用删除边界，预览不能通过接口单独删除。引用写入必须与媒体行锁、状态和版本校验一起提交，防止永久删除后新增悬空引用。
- 仅移除素材库通过独立记录审计，不占用媒体生命周期事件的版本号。永久删除保留历史记录用于追溯，历史引用不能用于恢复已删除文件。
- 文件清理每 30 秒检查待处理记录，存储失败会延后重试；接口区分保留、待清理、独立副本仍使用和已清理，不将排队视为文件已删除。
- 本轮没有新增兼容分支或静默回退。当前删除范围不包括外部公开 URL、本机之外已下载的副本或用户自行保存的备份。
- 生成联调使用本地模拟图片服务，核对任务状态和供应商请求参数，没有调用付费图片供应商接口。存储验证覆盖本地文件与隔离 MinIO，未修改用户已有数据库或存储配置。
