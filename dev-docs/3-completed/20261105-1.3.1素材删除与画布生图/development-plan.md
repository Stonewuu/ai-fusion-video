# 1.3.1 素材删除与画布生图

## 范围

- 在媒体素材库提供删除操作。用户明确选择两种方式：仅从素材库移除，或解除引用并永久删除。两种方式均重新检查用户与项目权限；永久删除预览影响范围，并处理重复请求及并发操作。
- 明确区分从生成输入移除参考图与从素材库删除素材，改善参考图移除入口。
- 画布生图与独立生图工作台共用比例、分辨率选择和参数校验；按模型支持的组合提交，不再提供与模型约束冲突的固定像素预设。
- 检查明暗主题、桌面与窄屏，以及表单聚焦、禁用、错误和滚动状态。

## 最终处理约定

- 仅从素材库移除不修改媒体版本，已有画布、业务内容和生成记录仍能读取。
- 永久删除清理当前画布配置及向下游提供素材的连线，通过已有业务命令清理项目媒体字段；保留历史审计记录，但相应媒体不可再读取或恢复。原素材的派生预览一并处理。
- 存在运行中任务、系统预设或无法修改的当前引用时，弹窗说明原因并阻止永久删除，仍允许从素材库移除。
- 独立副本继续可用。只有最后一份有效副本被删除后才清理共享文件；文件清理在数据库事务外执行，失败保留待处理状态并自动重试。

## 验证重点

- 图片模型的自动尺寸、档位与像素协议、比例切换、模型切换、自定义宽高冲突和保存后运行。
- 私有素材、团队素材、项目成员与撤权后的删除权限；已有画布和生成任务引用的处理；重复与并发删除。
- 迁移命名、全新数据库和从已发布版本升级后的 Flyway validate。
- 素材删除与参考图移除入口，以及共享输出控件在不同主题和视口下的边框、焦点和可操作性。
