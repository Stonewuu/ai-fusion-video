# 视频引用与贰春复验交付记录

本轮改动归入 1.3.1，完成代码与页面验收，产品版本尚未发布。

## 引用和批量生成

- 视频、音频引用使用托管媒体上传接口，生成请求保留原始媒体引用；不支持视频引用的模型明确提示，避免用封面替代视频。
- 再次使用恢复原模型、提示词、参数、首尾帧及图片、视频、音频引用；移除只改变当前输入，连续快速移除和添加也使用更新后的表单内容。
- 历史记录展示视频、音频引用，参考视频任务显示对应模式。已删除接入时误加的 `maxCount: 1`，本地四个贰春模型通过配置页修正，多结果生成沿用任务拆分、并发额度与排队机制。

## 参数控件与赞助信息

- 所有时长使用滑条，离散秒数按选项位置映射，保持供应商允许的取值；图像与视频共用画幅、分辨率选择器。
- 比例、分辨率、数量和时长保持等宽、同高，模型选择器单独固定宽度。分辨率通过像素网格密度区分，单一选项保持完整禁用控件。
- 贰春跳转地址改为 `https://youkou.cc/`，保留第三个赞助商位置。中英文 README 更新赞助内容，使用用户提供的图片。

## 验证与供应商结果

- 前端 34 项回归、TypeScript、改动文件 ESLint 通过。Chrome 验证上传、历史引用、恢复、连续移除添加，以及桌面、390px、320px、明暗主题、焦点与禁用状态；桌面参数 128×36px，窄屏 112×36px，切换内容后位置不变。
- 后端本轮 30 项测试通过，覆盖协议、多结果拆分、并发排队、重启后的回执隔离和查询间隔。打包、启动成功，Flyway 校验 37 条迁移通过，没有新增迁移。
- MiniMax-H3-DMC 参考视频任务 258272 成功，文件为 H.264/AAC MP4、1344×768、1.625 秒，保留蓝色立方体与浅色背景，净扣费 0.07 credits。
