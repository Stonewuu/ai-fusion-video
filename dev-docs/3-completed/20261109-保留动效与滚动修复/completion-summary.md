# 保留动效与滚动修复

已在 v-1.3.1 完成并在本地生效，尚未发布。助手三层波纹和认证页动态点阵已恢复；侧栏保留悬停反馈，分镜表格改为单向跟随横向滚动。

后续用户反馈侧栏快速移动仍有延迟，已在“20261110-全页面侧栏响应优化”进一步处理。本记录的 0%–1% 采样仅覆盖当时较低频率的移动，不能作为高频悬停场景的验收结论。

## 最终实现

助手波纹只使用位移、缩放与透明度，在 96px 局部区域绘制；收起状态不再叠加背景模糊。展开时卸载波纹，收起时恢复，页面不可见时暂停，减少动态效果模式显示静态状态环。

认证背景使用 Canvas 2D 代替全屏 WebGL。按 CSS 像素创建一屏大小的画布，每 100ms 更新一组点，每个点五秒变化一次。只在登录、注册、初始化和找回密码路由挂载，离开后取消定时器与尺寸监听并释放画布。系统动态偏好变化立即生效，同一次成功状态只触发一次完成回调。

侧栏取消整栏背景模糊，限制重绘范围，将 transition-all 改为颜色过渡。分镜表格删除表头、表体双向 scrollLeft 回写与逐帧锁，表体控制滚动，表头通过 transform 跟随；保留表头吸顶、横向与 Shift 滚轮、列宽调整、行内编辑定位，取消表格与表头叠加模糊。

## 验证结果

6 个行为测试、TypeScript、修改文件 ESLint、最终生产构建及差异格式检查通过。Chrome 检查横向反向滚动、右侧字段编辑定位和列宽调整，表头与表体对齐；4 倍 CPU 限速下也完成滚动及编辑检查。明暗主题、助手首次输入及收起后的三层波纹正常，页面未记录控制台错误。

认证组件预览检查动态点阵、减少动态效果、运行中切换偏好、成功回调恰好一次及离开页面后的卸载。390×844 长表单检查首、中、末项焦点、校验边框和禁用状态，画布高度不随内容增加。

恢复动画后，本机 Chrome GPU 进程在侧栏连续悬停和认证预览稳定运行时，各 10 次采样均为 0%–1%。此次没有复现持续满载；采样条件、自动化移动频率和未覆盖范围已记录在 technical-debt.md，不能外推到所有显卡和屏幕。

原有前后端保持运行，临时预览已停止；测试视口、CPU 限速、动态偏好、主题和列宽已恢复。共享 UI 源码和业务数据没有修改。
