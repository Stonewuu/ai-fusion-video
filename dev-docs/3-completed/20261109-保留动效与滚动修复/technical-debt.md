# 验证边界

本次没有增加协议兼容层或性能模式入口。共享 UI 源码保持不变，素材占位图去除重复流光与模糊的优化继续保留。

GPU 数据来自本机 Windows 性能计数器，按 Chrome GPU 进程汇总，整数采样不代表完全不使用 GPU。分镜页约 1251×1244，认证预览约 1251×1188；不与上一轮不同视口的静态方案直接计算降幅。浏览器自动化的连续悬停约一秒一次，没有覆盖所有设备和鼠标移动频率；4 倍 CPU 限速也不等同于低配显卡。

认证背景的绘制暂停、恢复及卸载通过定时器行为测试和组件页面验证；页面可见性由 visibilitychange 订阅控制。本地登录状态保持不变，登录表单和完成跳转在独立组件预览中验证，没有重新执行账号认证。
