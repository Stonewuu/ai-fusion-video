# 当前进度

已在 v-1.3.1 完成代码修改、Chrome 页面验证和最终生产构建，本地修改已生效，尚未发布。

## 已完成

- 助手恢复三层扩散波纹，只改变 transform 和 opacity，并将绘制限制在按钮周围 96px 的区域。收起状态去掉背景模糊，展开后波纹卸载，收起后恢复；页面不可见时暂停。原有首次点击修复保留。
- 认证页恢复蓝色动态点阵，使用 Canvas 2D 按 CSS 像素绘制，每 100ms 只更新一组点，每个点五秒变化一次。背景尺寸固定为视口，长表单不会扩大画布；认证路由之外不挂载，卸载时取消定时器、尺寸监听并释放画布。
- 使用可订阅系统偏好的 Hook，让减少动态效果的设置立即生效。验证中发现零时长成功过渡会重复触发回调，已确保同一次成功状态只执行一次跳转。
- 侧栏改为实体表面并限制重绘范围，悬停只过渡颜色；保留导航进场与选中反馈。
- 分镜表体成为唯一横向滚动源，表头通过位移跟随；删除双向 scrollLeft 回写和逐帧锁。表头支持横向滚轮与 Shift 滚轮，列宽、视口变化后重新对齐；移除表格和表头叠加的背景模糊。

独立认证组件预览验证动态点阵、普通和减少动态效果模式、运行中切换偏好、成功回调恰好一次、离开路由后 canvas 数量为 0。390×844 长表单检查首、中、末字段的焦点与校验边框和禁用状态，画布始终为 390×844。没有退出用户账号。
