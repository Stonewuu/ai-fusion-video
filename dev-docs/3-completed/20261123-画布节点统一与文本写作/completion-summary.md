# 画布节点统一、文本 AI 写作与画布视觉交互升级交付

完成画布节点的统一外观与交互、文本节点 AI 写作与结果写回、独立的精密画布组件库、模型厂商图标与实时搜索、参考素材快捷管理，以及输入端口反向拖线添加前置节点。

## 最终范围与关键实现

- **画布专用组件库（`components/canvas/ui/`）**：与 `components/ui/` 完全独立，覆盖节点、快捷面板、悬浮工具条、选中工具条、右键/添加菜单、状态栏和空状态。采用同心圆角阶梯（控件 10px/8px、文本域与引用卡 12px、工具条与右键菜单 14px、节点与下拉浮层 16px、快捷面板 20px）、细腻微边框、多层柔影、品牌色 3px 焦点外圈，以及克制的反色单色高质感生成按钮（去除花哨渐变与魔法星图标）；同步更新 `AGENTS.md`。
- **画布整体层次与节点细节**：微灰/深炭点阵底色拉开与节点卡片的前后层次；节点标题采用类型色圆角图标底托与清晰状态微标；多输出节点右侧圆形 `+` 按钮位于右上外侧，避让输出端口名称；`canvas-node.tsx` 精简为 260 行分组专用渲染。
- **生成表单与全节点悬浮面板**：
  - 宽度统一 560px，统一 12px 水平栅格（引用卡、主输入框、单行底栏 0px 齐平）；生成表单支持上游引用卡、紧凑输出摘要（`Ratio` 图标）与 `Ctrl/⌘ + Enter` 快捷生成。
  - **正文/故事/备注面板（`TextComposer`）**：单行 52px 底栏，左侧为轻量无框「`↳ 下一步` + 生成图片 / 生成视频 / 生成文本」（悬停 Tooltip 明确新建下游连线意图），右侧为 `完成` / 反色单色 `保存`；修复 `Esc` / 关闭 / 失焦点击竞态，确保改完一点即保存且不丢稿。
  - **媒体节点悬浮面板（`MediaNodePanel`）**：覆盖图片、视频、音频、文本文件、文档节点；默认紧凑 2 行（名称输入 + 放大预览 + 更换媒体 + 收起；底栏提供对应媒体类型的快捷下一步与保存/完成），展开「更换媒体」直接在面板内搜索或上传替换。
  - **通用节点悬浮面板（`NodeFloatingPanel`）**：覆盖其余全部配置、运行、分组与项目内容引用节点，支持名称编辑、输入来源管理、配置字段、运行与保存；点击任何画布节点均不再弹出右侧属性栏挤压画布（右侧「编辑」仅保留给连线与多选），并移除旧右侧 `CanvasNodeInspector` / `CanvasNodeIdentity`。
  - **悬浮视口定位与防裁切（`CanvasNodePanel`）**：支持按实时下方可用空间动态约束面板最大高度并保留 32px 底边余量，展开内容不跳镜头，嵌套 Dialog/Popover 按 `Esc` 仅关闭上层弹层。
- **悬浮停靠栏与毛玻璃侧边抽屉**：彻底移除画布左右常驻的 `64px` 实心白条，释放 100% 全宽点阵画布；左右边缘垂直居中改为轻巧的 `40px` 悬浮停靠胶囊（支持运行中/待确认/选区角标提示），点击后以平滑的 Framer Motion 位移缩放动效滑出 `20px` 圆角毛玻璃悬浮抽屉（`top/bottom: 64px` 对称避让顶部工具栏与底部状态栏，零挤压、零重排画布），支持 `CanvasSegmented` 页签切换、`Esc` 收起与焦点还原；全部 6 个抽屉页签（项目、素材、选区/连线、运行、评论、历史）内部控件与卡片统一采用画布设计语言。
- **模型列表图标与实时搜索**：后端 `CanvasModelCatalog.Option` 透出 `code`、`platform`、`capabilityPresetCode`；画布 `CanvasPicker` 与属性面板 `CanvasSelect` 均展示 `ModelVendorIcon` 彩色厂商图标与等宽模型编码，选项超过 7 项时自动开启实时搜索与键盘导航。
- **文本节点 AI 写作与写回**：后端 `CanvasGenerationInputPreview` 放开 `TEXT_GENERATION`；点击文本面板「AI 写作」在右侧就近空位创建并连线「生成文本」节点，结果直接展示在节点内容框中，当前有效且来源为文本节点的结果支持一键写回正文并可撤销；同步补齐 `CanvasApprovalText` 中 `additionalPrompt` 中文名。
- **参考素材等高对齐与快捷断开**：参考图以 `object-cover` 铺满 36×36 缩略框，文本引用芯片与图片严格 36px 等高对齐，两者悬停或聚焦右上角均提供一键断开连线按钮（支持撤销）。
- **输入端口反向拖线添加前置节点**：从任意空闲且无手填值的左侧输入端口拖线到画布空白处松手，弹出「添加前置节点」菜单，按类型、集合约束与项目作用域过滤兼容来源节点并自动预填唯一确定的动态输出类型；选择后在松手点左侧创建前置节点并分配下一个空闲 `inputIndex` 自动连线。

## 验证结果

- 前端：TypeScript 零错误、`components/canvas` 与 `lib/canvas` ESLint 0 error / 0 warning、85 项画布单元测试全部通过（含写回、就近放位、前置兼容节点、全节点悬浮面板路由新增用例）。
- 后端：画布相关单元测试全部通过（含生成文本输入预览、非生成节点拒绝、模型目录扩展字段与审批字段名校验）。
- Chrome 浏览器验收：浅色与暗色双主题全景与 2x 特写核对通过，覆盖视频/图片/文本生成表单、模型厂商图标与实时搜索、正文面板、参考素材铺满/等高/悬停断开、输入端口拖线添加前置节点、多输出加号避让、0px 边缘齐平与暗色 3px 品牌焦点环；测试节点与草稿均已清理，画布保持原状与浅色模式。
