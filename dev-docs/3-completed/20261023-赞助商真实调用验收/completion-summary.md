## 发现与修复

独立验收库没有默认媒体存储，补齐后继续保存已收到的结果。大体积 Base64 图片还暴露出共享任务队列的 MySQL 排序故障：领取查询 SELECT * 将完整结果 JSON 带入排序，耗尽默认排序缓冲并阻塞其他任务。

RemoteGenerationJobMapper 的候选查询改为只读取领取和额度所需的七个字段；GenerationJobRepository 在领取后按主键读取完整输入与结果，保留原有锁、额度、租约和状态约束。没有修改数据库迁移或生产排序缓冲配置。

扩展已有 GenerationJobPersistenceIT 的入库恢复与额度用例，使用有效的大体积 PNG 响应。原查询能复现 MySQL 1038，修复后全部 9 项测试通过，保护大结果恢复、独立任务领取、并发额度及提交幂等行为。更新后的验收服务恢复原图片和秘塔任务，并完成已排队的星河任务。
