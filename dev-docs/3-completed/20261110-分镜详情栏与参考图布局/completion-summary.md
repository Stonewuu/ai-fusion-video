# 分镜详情栏与参考图布局

2026-11-10 在 v-1.3.1 工作区完成，本地已生效，尚未发布。

## 最终行为

单元格采用用户选择的整格高亮：4px 圆角、淡色背景、细边框，保留点击编辑提示和键盘焦点，移除铅笔及其占位。

首尾帧的图片、空上传区及空链接预览均使用 3:2 比例；图片完整显示，剩余区域使用背景色留白。右侧详情栏可在工具栏收起和展开，收起后释放 288px 宽度，保留当前选中镜头与面板内部状态，并记住当前浏览器的收起偏好。

修复子资产图片显示不一致：详情栏不再用主资产封面代替缺图子资产。平台响应中“雨中湿透的陆阳”的子资产图片为空，之前右侧显示的是陆阳主资产封面；现在表格和详情栏都按子资产本身的状态展示。

## 验证

Chrome 项目页面确认首尾帧区域约为 245×163.33px，收起后表格由 894px 扩至 1182px，展开后镜号和链接模式保留，刷新后收起偏好有效。横向滚动表头与正文保持对齐，键盘进入和取消编辑正常。

隔离页面使用项目组件验证横图、竖图及空图片的 288×192px 区域、图片完整显示、明暗主题、窄屏输入焦点，以及缺图变体不使用父资产封面、有图变体使用自身图片。另验证了 1024px 视口的详情抽屉。生产构建和六项列宽、滚动回归测试通过。

## 范围

没有生成、上传、删除或修改项目图片，也没有修改模型配置和分镜内容。用户原标签中的编辑操作未被取消或提交。验证标签和服务已关闭，原本地前后端保持运行。
