# 分镜详情栏与参考图布局

采用用户选择的整格高亮编辑提示：悬停时显示淡色背景、小圆角细边框，移除铅笔，保留点击编辑提示和键盘焦点。

首尾帧参考图使用固定 3:2 显示区域，图片按原始比例完整显示，剩余区域留白。空上传区、链接模式和已有图片使用一致比例。

桌面右侧详情栏增加收起、展开入口，收起后主表格使用释放的空间；保留所选镜头和面板状态，并记住收起偏好。窄屏继续使用现有详情抽屉。

验证实际页面的悬停、编辑取消、参考图区域尺寸、收起展开、刷新偏好和横向滚动；图片比例与输入状态使用隔离页面验证，不修改项目数据。

修正关联资产缩略图：明确关联到子资产时，只展示该子资产图片，不在缺图时使用主资产封面。主资产本身的展示仍可使用主资产封面。
