# 处理过程

1. 失败任务同时记录了竖图比例和横图像素尺寸。原选择器分别列出比例和像素，允许用户提交相互矛盾的组合。本地两个 2.5 型号也都引用了 Image 2 的预设。
2. 为两个 2.5 型号分别配置预设，并按比例筛选可用档位。用本地 HTTP 测试确认标准图片请求的字段后，网关仍返回 400。对照同一次请求进出网关的记录，确认网关统一添加了 `service_tier=default`。
3. 按要求备份网关配置并删除添加该参数的规则。网关重新加载配置后，两种 2.5 型号均已出图。
4. 将比例和分辨率改为图形选项，统一快捷模式和高级模式。成功提交时只更新记录，保留失败原因与中断后的确认入口。
